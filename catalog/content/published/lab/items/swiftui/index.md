# SwiftUI

SwiftUI 是 Apple 平台的声明式 UI 框架。它用状态驱动视图更新，通过组合 View、修饰符、布局容器和数据绑定构建 iOS、macOS、watchOS、tvOS 等平台界面。

## 适合关注什么

- 声明式 UI 与 UIKit/AppKit 命令式 UI 的差异。
- `@State`、`@Binding`、`@Observable`、环境值和数据流。
- View 生命周期、布局系统、动画、导航和平台适配。

## 使用边界

SwiftUI 适合构建现代 Apple 平台界面，但复杂项目仍可能需要与 UIKit/AppKit、系统权限、异步任务、持久化和架构分层配合使用。
