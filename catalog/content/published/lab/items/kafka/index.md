# Apache Kafka

Apache Kafka 是一个分布式事件流平台。它把消息组织成可追加、可保留、可按分区扩展的日志，让多个消费者可以按自己的节奏读取同一份事件历史。

## 适合关注什么

- topic、partition、offset 和 consumer group 如何组成 Kafka 的消费模型。
- Kafka 为什么更像可重放的日志，而不是一次性取走的传统队列。
- 高吞吐写入、顺序消费、事件保留和多消费者解耦之间的关系。
- 在日志采集、事件驱动架构、流处理和数据管道中的使用边界。

## 使用边界

Kafka 适合高吞吐事件流、日志管道和需要重放历史的消息系统。它不适合低复杂度、小规模、强事务式任务分发场景；真实使用时还需要评估分区设计、消费积压、重复消费、消息顺序和集群运维成本。
