# Redis

Redis 是一个高性能内存数据结构存储，常用于缓存、计数器、排行榜、会话、分布式锁和实时状态读写。它的核心价值不只是“快”，还在于用简单的数据结构把高频访问路径从数据库压力中拆出来。

## 适合关注什么

- 字符串、哈希、列表、集合、有序集合等数据结构如何服务业务场景。
- 缓存命中、过期、淘汰、持久化和内存容量之间的取舍。
- Redis 在热点数据、会话状态、排行榜、限流和队列型场景中的边界。
- 从“内存快”进一步理解一致性、失效策略和运维风险。

## 使用边界

Redis 适合承载高频、低延迟、可按策略重建或可接受短暂不一致的数据访问路径。涉及强一致事务、复杂查询、长期主数据存储或不可丢失消息时，需要谨慎评估持久化、复制、故障切换和数据恢复策略。
