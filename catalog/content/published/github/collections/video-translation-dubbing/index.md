# 视频翻译配音工具

这个专题根据 `docs/notes/视频翻译配音_开源方案对比.md` 整理。它关注把一个 A 语言视频变成带 B 语言配音和字幕的视频本地化流程。

## 流程骨架

```text
视频 -> 语音识别 -> 字幕翻译 -> TTS 配音 -> 对齐合成 -> 成品视频
```

这些项目的价值在于把多步骤工具链编排成更容易复用的工作流。不同项目在翻译质量策略、配音对齐方式、部署形态和本地克隆 TTS 接入能力上差异明显。

## 音色克隆关系

视频配音工具通常不内置所有克隆模型。它们更像编排器和客户端，GPT-SoVITS、CosyVoice、F5-TTS、Fish Speech、XTTS 等 TTS 服务需要按项目能力单独部署和接入。
