为什么这篇使用 HTML 片段

这篇笔记不是完整 HTML 文档，而是放进本站统一页面壳层里的正文片段。它可以使用语义化结构和轻量 class， 但不携带脚本、head、body 或独立样式入口。

适合表达

  • 需要比 Markdown 更精细的局部结构。
  • 希望沿用本站导航、背景和正文排版。
  • 不需要独立脚本或完整页面资源。

不适合表达

  • 完整实验 demo 页面。
  • 带脚本交互的私人工作台。
  • 依赖外链样式或局部全局样式覆盖的页面。

对 GPT-SoVITS 来说，这种站内 HTML 片段适合写“观察卡片”“参数对比说明”或“流程拆解”， 而完整试验记录仍然应该使用独立 HTML 页面。
