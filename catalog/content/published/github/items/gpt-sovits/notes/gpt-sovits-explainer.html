Few-shot Voice Cloning · TTS

GPT-SoVITS
一分钟语音，克隆一个声音

GPT-SoVITS 是由 RVC-Boss（花儿不哭）于 2024 年 1 月开源的少样本语音克隆与文本转语音（TTS）框架。 仅需约 1 分钟的目标说话人录音即可微调出高相似度的音色模型；甚至只用一段 5 秒参考音频，也能进行零样本（Zero-shot）合成。

开源 · MIT 协议 中 / 英 / 日 / 韩 / 粤 Zero-shot & Few-shot GitHub 6 万+ Star

它是什么？

一句话：把「GPT 式语言模型」和「SoVITS 声学模型」拼在一起的语音克隆系统

传统 TTS（如早期的 Tacotron、FastSpeech）想合成某个人的声音，往往需要数小时的高质量录音来训练。 GPT-SoVITS 的突破在于把需求压缩到了极致：1 分钟语音即可微调（Few-shot），5 秒参考音频即可直接推理（Zero-shot）， 并且合成结果在音色相似度、自然度上都达到了可实用的水平。

名字中的两个部分对应它的两阶段架构：GPT 指一个自回归 Transformer，负责「决定说什么、怎么说」（语义与韵律）； SoVITS（源自 SoftVC + VITS）负责「用谁的声音说出来」（音色与波形生成）。

架构原理：两阶段流水线

文本 → 语义 token → 声学波形

GPT-SoVITS 借鉴了 VALL-E 等「语言模型式 TTS」的思路，把语音合成拆成两步。 关键中间产物是语义 token（semantic tokens）——由自监督语音模型（HuBERT 类）提取并量化得到的离散单元， 它编码了「说了什么内容、什么节奏」，但基本剥离了音色信息。

输入：目标文本（转为音素）＋ 参考音频（5 秒左右）
↓
STAGE 1 · GPT（自回归 Transformer）

以文本音素和参考音频的语义 token 为提示（prompt），像语言模型「续写」一样， 逐个预测目标语音的语义 token 序列。 这一步决定了发音、停顿、语速、韵律——即「怎么说」。参考音频在此充当风格示例，让模型模仿其说话习惯。

↓ 语义 token 序列
STAGE 2 · SoVITS（VITS 声学模型 + 音色编码）

基于 VITS（变分推断 + 对抗训练的端到端声学模型），把语义 token 序列还原成真实波形。 同时从参考音频中提取说话人音色特征注入解码器——即「用谁的声音说」。 由于语义与音色解耦，换参考音频就等于换嗓子。

↓
输出：目标说话人音色的语音波形

为什么这样设计有效？

解耦是核心思想：内容/韵律（Stage 1）与音色/声学细节（Stage 2）分开建模。 GPT 部分在大规模多说话人数据上预训练，学到了通用的「语音语法」；微调时只需少量数据让两个模型适配新音色， 因此 1 分钟数据就够。这也是它跨语言合成的基础——语义 token 是跨语言相对通用的表示。

使用流程

WebUI 中的典型微调路径（0 → 专属音色模型）

  1. 准备素材

    收集目标说话人 1～5 分钟的干净录音（无 BGM、无混响为佳）。WebUI 提供人声分离（UVR5）、切片、降噪工具。

  2. 自动标注

    用内置 ASR（中文常用达摩院 FunASR，英文/日文用 Faster-Whisper）自动生成文本标注，并可人工校对。

  3. 特征提取与训练格式化

    一键完成文本音素化、HuBERT 语义 token 提取、说话人特征提取等预处理。

  4. 微调两个模型

    分别微调 SoVITS（声学/音色）和 GPT（语义/韵律）权重，消费级 GPU 上通常十几分钟内完成。

  5. 推理合成

    在推理页选择模型 + 一段参考音频（附文本），输入任意目标文本即可合成；可调节语速、切句方式、top_k / temperature 等采样参数。

经验提示：参考音频的选择对结果影响极大——它的情绪、语气会直接迁移到输出。想要平稳旁白就选平稳的参考片段，想要激动语气就选情绪饱满的片段。

与相关项目的区别

经常被放在一起讨论的几个开源项目

项目类型与 GPT-SoVITS 的差异
So-VITS-SVC 歌声/语音转换（SVC） 做「变声」：输入必须是一段人声，把它换成目标音色，不能凭文本直接合成。GPT-SoVITS 是 TTS，输入是文本。
RVC 实时变声（VC） 同为变声器，主打低延迟实时转换；同样不具备文本转语音能力。作者与 GPT-SoVITS 为同一人。
Bert-VITS2 TTS 同为克隆式 TTS，但通常需要更多训练数据、更长训练时间；GPT-SoVITS 在少样本与零样本场景优势明显。
VALL-E / CosyVoice 等 LM 式 TTS 思路同源（语言模型 + 离散语音 token）。GPT-SoVITS 的特点是完全开源、可本地微调、社区生态与整合包成熟。

应用场景与使用边界

能做什么，以及不该做什么

常见应用：有声书与配音生产、虚拟主播/游戏角色语音、个人语音助手定制、视频解说批量配音、 语言学习发音示范、为失声者保留个人声音等。配合流式推理接口，也被用于实时对话式应用。

伦理与法律边界：克隆他人声音必须取得声音主人的明确授权。 未经许可克隆真人声音用于诈骗、造谣、冒充身份等行为在多数司法辖区已属违法（中国《民法典》明确保护自然人声音权益，深度合成内容需显著标识）。 项目本身也在协议中要求使用者对合成内容负责。技术无罪，用法有界。
