# ComfyUI

ComfyUI 是一个节点式 AI 生成工作流引擎。它把扩散模型推理拆成可连接、可复用、可保存的节点图，让用户用图形化方式编排文本编码、采样、解码、ControlNet、LoRA、放大、视频或音频生成等步骤。

## 适合关注什么

- 用节点图理解 Stable Diffusion、Flux、SD3 等生成流程。
- 将一次生成流程保存为 JSON 或嵌入图片，便于复现、分享和自动化调用。
- 通过自定义节点、ComfyUI Manager 和工作流模板扩展生成能力。
- 把 ComfyUI 后端当作可通过 HTTP/WebSocket 调用的生成服务。

## 使用边界

ComfyUI 更适合需要精细控制生成链路、复用复杂工作流或做模型实验的用户。相比固定表单式 WebUI，它的学习成本更高；真实部署时还需要额外评估模型授权、显存占用、节点依赖、工作流来源和生成内容合规风险。
