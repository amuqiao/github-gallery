Model Explained · TimesNet · ICLR 2023 · Tsinghua THUML

把一维时间序列折成二维张量,然后像看图片一样用 2D 卷积去看它

TimesNet 做的事情一句话就能说完:用 FFT 从数据里找出几个主要周期,按周期把序列折叠成二维"图像",让 2D 卷积同时捕捉"周期内变化"和"周期间变化"。靠这一个骨干,它同时覆盖预测、补全、分类、异常检测等任务。下面这张动图就是它的全部核心。

任务:通用时间序列分析 输入:[B, T, C] 多变量序列 骨干:FFT + 2D Inception 卷积 不含 attention
1D series [T=96] → fold by period p=24 → 2D tensor [4 × 24] 值的高低:低中高
01 · WHY / 它为什么出现

要解决的真实任务:一套骨干,吃下所有时间序列分析

2022 年前后,时间序列领域每个任务各有一套"最强模型":预测看 Transformer 变体,分类看专门的卷积网络,异常检测又是另一批方法。TimesNet 的目标是做一个任务无关的通用骨干(task-general backbone):同一个网络结构,换个输出头,就能覆盖五类任务。

此前方法卡在哪

  • 1D 卷积:感受野贴着时间轴,只能看局部邻居,想看"上一个周期的同一时刻"需要堆很多层。
  • Transformer / attention:逐时间点算相似度,但单个时间点数值太"薄"(就一个标量/向量),点对点注意力很难稳定挖出周期结构。
  • 共同盲区:都把序列当纯一维处理,而真实序列(电力、交通、气象)往往同时叠着多个周期——日周期套着周周期,周周期套着年周期。

TimesNet 的切入点

一个周期为 24 的序列,折成每行 24 个点的二维网格后:

  • 沿行看(intraperiod):一个周期内部的形状变化,比如一天内的早晚高峰;
  • 沿列看(interperiod):相邻周期同一相位的演化,比如"每天早上 8 点"这个量逐日的走势。

两种变化在 2D 里变成了相邻像素,一个普通的 2D 卷积核就能同时覆盖——这正是视觉模型最擅长的事。

一句话定位:TimesNet 不是"又一个预测模型",而是把"时间序列 → 2D 表示"作为通用地基,让 CV 里成熟的卷积套路可以直接搬过来。发表时它在长/短期预测、补全、分类、异常检测五类任务上同时拿到 SOTA 或接近 SOTA。
02 · I/O / 输入是什么,输出是什么

输入输出:同一骨干,四种头

骨干的输入永远是一个形状 [B, T, C] 的张量:B 条样本、每条 T 个时间步、每步 C 个变量。任务不同,变的只是拼在骨干后面的输出头和损失函数。点开每个任务看它的具体进出:

历史窗口[B, 96, 7]→ backbone →未来 pred_len 步[B, 96, 7]

例:ETTh1 电力变压器数据,7 个变量,用过去 96 小时预测未来 96 小时。特别之处:TimesNet 先用一个线性层把序列从 96 步"拉长"到 96+96=192 步,再让骨干在整段(历史+粗糙未来)上反复精炼,而不是像 encoder-decoder 那样分两半。损失用 MSE。短期预测(如 M4 数据集)同理,只是窗口更短。

带缺失的序列 + 掩码[B, 96, 7] + mask→ backbone →补全后的完整序列[B, 96, 7]

缺失位置置 0 并给模型掩码;骨干输出每个时间步的重建值,只在缺失位置计算 MSE。周期结构在这里特别有用:缺掉的"周二早高峰"可以从其它周二的同相位学回来。

一整段序列[B, T, C]→ backbone → flatten →类别 logits[B, num_class]

例:心电、动作识别等 UEA 数据集。骨干输出 [B, T, d_model] 后展平接一个线性层,交叉熵训练。这是 TimesNet 相对 Transformer 系模型优势最明显的任务之一——分类更依赖"形状特征",卷积天然擅长。

滑动窗口[B, 100, C]→ backbone →逐点重建 + 重建误差[B, 100, C]

自监督重建:训练时让模型重建正常序列;推理时重建误差大的时间点判为异常(误差超过某个分位数阈值)。输出本质是"每个点有多不像正常模式"。

边界:它默认你给它什么

  • 等间隔采样的规则序列(小时、天、分钟级都行);不规则采样/事件流需要先重采样。
  • 数值型变量;类别特征要自己编码。时间戳特征(几点、星期几)可作为额外 embedding 输入。
  • 输入窗口 T 是硬边界:FFT 只能看到长度 ≤ T 的周期。窗口 96 小时的模型不可能利用"周周期"(168 小时)。
03 · KEY IDEA / 亲手折一次

核心思想:FFT 找周期 → 按周期折叠 → 2D 卷积

下面是一个可以动手玩的最小演示。左边是一条合成序列(叠了周期 24 和周期 8 两个成分),右上是它的 FFT 振幅谱——TimesNet 就是从这张谱里挑振幅最大的 top-k 个频率,换算成周期。点谱线或按钮,看看折对周期和折错周期的二维图差别有多大。

折叠周期 p:
① 原始 1D 序列(T = 192)= 1.2·sin(2πt/24) + 0.7·sin(2πt/8) + …
② FFT 振幅谱(点击谱线选周期,橙色 = top-2)
③ 按 p=24 折叠 → 2D 张量 [8 行 × 24 列]

为什么折对了会出现"竖条纹"

折叠周期 = 真周期时,每一行都是一个完整周期,所有行的相位对齐:同一列 = 同一相位(比如都是"早上 8 点")。数值相近的点排成竖直条带,2D 卷积核扫过时,横向邻居是周期内的前后时刻,纵向邻居是相邻周期的同一时刻——两类信息一次卷积全拿到。

折错了会怎样

p=17 时相位每行漂移,条纹变斜、图案错乱,卷积很难学到稳定模式。这就是为什么周期不能随便定,必须由 FFT 从当前这批数据里现算——也是 TimesNet 与"手工指定周期"方法的本质区别。噪声和趋势会让谱线变脏,但主峰通常仍然清晰,试试勾选上面的开关。

多周期怎么办?真实序列往往有好几个周期。TimesNet 对 top-k 个周期各折一次、各卷一次,得到 k 个结果,最后按各频率的 FFT 振幅做 softmax 加权求和——振幅越大的周期,话语权越大。这个聚合权重来自数据本身,不是学出来的参数。
04 · DATA FLOW / 从输入到输出

数据流全景:一个张量的旅程

以最常用的长期预测为例(ETTh1:B=32,历史 96 步,预测 96 步,7 个变量,d_model=64,top_k=5,e_layers=2)。点击下面任意阶段,或用"上一步 / 下一步"走一遍:

TimesBlock 内部再放大一层

整个模型 90% 的功夫都在 TimesBlock 里,它每次前向做五件事:

[B, T, d]→ FFT 选 top-k 周期 → k 个 [B, d, 行, 列]→ Inception 2D 卷积 → k 个 [B, d, 行, 列]→ 展平 + 振幅加权 → [B, T, d]+ 残差
  • FFT 找周期:对时间维做 rfft,振幅在整个 batch 和全部通道上取平均(所以所有变量共享同一组周期),去掉直流分量后取 top-k,周期 p = T // 频率。
  • 折叠:T 不整除 p 就先 padding 补零,再 reshape 成「行 = 周期个数,列 = 周期长度」的 2D 张量,d_model 个通道相当于图像的通道数。
  • Inception Block V1:并联 num_kernels 个不同大小的 2D 卷积核(1×1, 3×3, 5×5 … 11×11),输出取平均。多尺度核 = 同时看细粒度和粗粒度的 2D 模式;k 个周期分支共享同一组卷积参数,参数量不随 k 增长。
  • 展平回 1D:reshape 回 [B, T', d],截掉 padding 部分。
  • 自适应聚合:k 个分支按对应频率的振幅 softmax 加权求和,加上残差连接。
因果链条捋一遍:数据有周期 → FFT 谱上出现高振幅峰 → 峰决定折叠方式 → 折叠让两类时间关系变成空间邻居 → 2D 卷积捕捉它们 → 振幅决定各周期结果的权重。数据的周期结构从头到尾牵着模型走,这是 TimesNet"自适应"的含义。
05 · TRAIN vs INFER / 学什么,算什么

训练时学什么,推理时算什么

训练时,梯度更新的是

  • Embedding:把 C 个变量映射到 d_model 的 1D 卷积 + 时间特征 embedding;
  • predict_linear(预测任务):把 T 拉长到 T+H 的线性层;
  • Inception 卷积核:每层 TimesBlock 里那组 2D 卷积——模型的"主力参数";
  • LayerNorm 与输出头:投影回 c_out 或类别数的线性层。

损失:预测/补全/异常用 MSE,分类用交叉熵。优化器 Adam,lr 约 1e-4~1e-3,ETT 这类小数据集单卡几分钟一个 epoch。

推理时,每次前向现算的是

  • FFT 与周期选择:周期不是模型参数,是对当前输入现场算出来的——换一批数据,折叠方式自动变;
  • 聚合权重:来自当前输入的频谱振幅,同样不是参数;
  • 归一化统计量:用当前窗口的均值/方差做标准化,输出后再乘回去(对抗分布漂移的关键一步)。

这带来一个少有人说破的性质:TimesNet 的"结构"随输入自适应,但"参数"完全静态——部署后不需要任何在线更新。

哪些旋钮真正影响结果

旋钮典型值影响
seq_len(输入窗口)96 / 336 / 512最重要。决定 FFT 分辨率和能"看见"的最长周期;想利用周周期,窗口必须 ≥ 一周。
top_k5参与折叠的周期个数。调大计算量线性上涨,而弱周期常是噪声,通常 3~5 就够。
d_model / d_ff16~64 / 32~128通道宽度。TimesNet 论文配置出奇地小(ETT 上 d_model=16),调大易过拟合小数据集。
e_layers2TimesBlock 层数,2 层几乎是所有基准的默认。
num_kernels6Inception 并联核数(1×1 到 11×11)。
训练数据的周期结构—卷积核学的是"折叠后 2D 图案"的模式;换到周期结构完全不同的域,需要重新训练或微调。
06 · COMPARE / 站在坐标系里看它

对比、误区与工程取舍

模型核心机制相对 TimesNet
DLinear (2023)一层线性映射(+趋势分解)参数量小几个量级、推理快得多;在不少长期预测基准上精度不输 TimesNet。如果只做预测且资源紧张,先试它。
PatchTST (2023)序列切 patch + Transformer,通道独立长期预测精度普遍更强;但只是预测模型,没有 TimesNet 的多任务通用性。
Autoformer / FEDformer (2021-22)频域/分解式 attention同样利用周期先验,但仍在 1D 上做 attention;TimesNet 用 2D 卷积替代,分类和异常检测上明显更强。
iTransformer (2024)把 attention 打在"变量维"而非时间维后来者,多变量长期预测精度大多超过 TimesNet;通用任务覆盖不如。
N-BEATS / N-HiTS堆叠 MLP 基展开单变量短期预测强;无 2D 结构、无多任务定位。

对比按各论文发表时的公开基准(ETT / Weather / M4 / UEA / SMD 等)概括,不同数据集上强弱会翻转,选型请以自己数据上的实验为准。

常见误区

"周期是 TimesNet 学出来的参数"

不是。周期由 FFT 对当前输入现算,每个 batch、每层都重新算。可学习的是折叠之后的卷积核。这也意味着:推理数据的周期若与训练数据一致,卷积核学到的 2D 模式才能对得上号。

"TimesNet 是 Transformer 的变体"

不是,它没有任何 attention,是纯卷积骨干(加上 FFT 这个无参数变换)。它经常和 Transformer 系模型同台比较,容易造成误会。

"数据没有明显周期就不能用"

能用——FFT 总能挑出 top-k 个频率,模型退化为"在几种任意折叠上做卷积",不会崩,但拿手好戏没了。这种数据上 TimesNet 相对简单基线的优势通常很小。

"top_k 越大、d_model 越大越好"

top_k 增大计算量线性上涨,而排名靠后的"周期"多半是噪声峰;论文配置 d_model 只有 16~64,盲目加宽在 ETT 这类小数据集上很快过拟合。

"每个变量各自找自己的周期"

官方实现里振幅谱在所有通道上取平均,全体变量共享同一组周期。如果你的变量周期差异巨大(比如小时级传感器混着周级指标),这是一个已知的结构性妥协。

工程取舍

  • 计算成本:FFT 是 O(T log T),大头在 2D 卷积——k 个周期分支各扫一遍全序列,再乘 num_kernels 个并联核。同精度下通常比 DLinear 慢一个量级以上,比多数 Transformer 变体省显存。
  • 序列很长时(T 上万):折叠出的 2D 张量面积 ≈ T,卷积成本与显存同步上涨,需要减小 top_k / num_kernels 或切窗口。
  • 导出部署:rfft 需要 ONNX opset ≥ 17;更麻烦的是 top-k 周期使 reshape 形状依赖数据,静态图导出会遇到动态 shape 问题——常见做法是导出时固定一组周期,或干脆用 TorchScript/eager 部署。
07 · HANDS-ON / 最小可运行示例

50 行读懂 TimesBlock,3 条命令跑通训练

下面的 PyTorch 代码是官方 TimesBlock 的忠实简化(去掉工程封装,保留全部逻辑)。高亮的三行就是整个模型的灵魂。

# timesblock_minimal.py —— 逻辑与官方实现一致的最小 TimesBlock
import math, torch
import torch.nn as nn, torch.nn.functional as F

class TimesBlock(nn.Module):
    def __init__(self, d_model=64, d_ff=128, top_k=5, num_kernels=6):
        super().__init__()
        self.k = top_k
        self.conv = nn.Sequential(          # Inception Block V1 ×2(此处以多尺度卷积示意)
            InceptionBlock2D(d_model, d_ff, num_kernels), nn.GELU(),
            InceptionBlock2D(d_ff, d_model, num_kernels))

    def forward(self, x):                 # x: [B, T, d_model]
        B, T, N = x.shape
        xf  = torch.fft.rfft(x, dim=1)                    # ① 频域
        amp = xf.abs().mean(0).mean(-1)     # 振幅谱:batch 与通道上取均值 → 全通道共享周期
        amp[0] = 0                          # 去掉直流分量(均值)
        _, freqs = torch.topk(amp, self.k)
        periods  = T // freqs               # 频率 → 周期长度

        outs = []
        for p in periods.tolist():
            pad = (math.ceil(T / p) * p) - T
            o = F.pad(x, (0, 0, 0, pad))                      # 补齐到周期整数倍
            o = o.reshape(B, -1, p, N).permute(0, 3, 1, 2)    # ② 折叠成 [B, d, 行, 列]
            o = self.conv(o)                                  # ③ 当"图片"卷
            o = o.permute(0, 2, 3, 1).reshape(B, -1, N)[:, :T]
            outs.append(o)

        outs = torch.stack(outs, dim=-1)                      # [B, T, d, k]
        w = torch.softmax(amp[freqs], dim=0)              # ④ 振幅越大权重越高
        return (outs * w).sum(-1) + x                     # 加权聚合 + 残差
完整模型 = Embedding → predict_linear(仅预测任务)→ [TimesBlock + LayerNorm] × e_layers → 线性投影头

08 · FIT CHECK / 判断清单

它适不适合你

适合 / 值得一试

  • 数据有清晰(甚至多重)周期:电力、交通流量、气象、零售、服务器指标
  • 想用一套骨干同时做补全、异常检测、分类,而不是每个任务养一个模型
  • 时间序列分类 / 异常检测——TimesNet 相对 Transformer 系的优势区
  • 想借鉴"1D→2D + 视觉骨干"的思路做自己的模型(论文证明换 ResNet/Swin 做 2D 部分也涨点)

不适合 / 先看别处

  • 只做长期预测、追求最高精度 → 先试 PatchTST / iTransformer,顺手跑个 DLinear 当基线
  • 非周期、事件驱动、不规则采样的序列 → 优势尽失
  • 极端低延迟或端侧部署 → 2D 卷积成本 + 动态 shape 导出麻烦,DLinear/线性类更省心
  • 超长输入(数万步)不切窗口 → 2D 张量与卷积开销随 T 线性膨胀
