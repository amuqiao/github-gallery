# 声音克隆项目

这个专题根据 `docs/notes/音色克隆开源方案对比.md` 整理。它把声音克隆、参考音频生成、多语言 TTS、音色转换和语音研究工具放在同一个策展列表里，方便横向比较不同路线。

## 三类路线

- 声音克隆 TTS：输入文本和参考音频，输出像参考音色说出的新语音。
- 声音转换 VC：输入源音频和目标音色，保留源音频语气并替换音色。
- 研究工具箱：覆盖 TTS、VC、SVC、vocoder 等多任务和多架构实验。

## 使用方式

专题顺序是人工策展顺序，不代表质量排名。项目的稳定事实仍来自各自 `project.yaml`，更细的优缺点、架构说明和选择建议保留在这份 Markdown 详情中。
