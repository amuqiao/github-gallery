01

「大小」不止一种算法

铺垫 1 / 2

先把「范数」这个词换成人话。它就是一把尺子，而尺子不止一把。

起点。这一节结束时，你会拿到一个旋钮。

手上有个向量 x = (3, −4, 1, 0)，它有多大？

这个问题没有唯一答案。至少有三种回答，而且三种都合理：

‖x‖₁ = |3| + |−4| + |1| + |0| = 8 全都加起来 ‖x‖₂ = √(3² + 4² + 1² + 0²) = √26 ≈ 5.10 勾股定理的推广 ‖x‖∞ = max(3, 4, 1, 0) = 4 只看最大的那个

这三个函数都叫范数——喂进去一个向量，吐出来一个非负实数表示「大小」， 分别记作 L1、L2、L∞。它们可以用一个参数 p 统一起来：

‖x‖ₚ = (|x₁|ᵖ + |x₂|ᵖ + … + |xₙ|ᵖ)^(1/p) p = 1 → L1　　p = 2 → L2　　p → ∞ → L∞（极限恰好就是取最大值）

这个通用形式叫闵可夫斯基范数。到这里，第一件重要的事已经出现了： p 是一个旋钮，你转到哪一档，就选定了一种「大小」的含义。

三者的性格差异只有一句话：p 越大，越只听大分量的话。 L1 一视同仁地把所有分量加起来；L2 因为要平方，大分量的贡献被放大； L∞ 干脆只看最大的那个，其余分量毫无发言权。

一个极容易记反的点。 常见说法是「L1 对异常值敏感，L2 更稳健」，实际恰好相反。 把某个分量从 10 改成 20：L1 读数增加 10，而 L2 的平方项从 100 变成 400，增加了 300。 L2 对异常值更敏感，L1 更稳健。记法：平方 = 放大 = 敏感。 这也是数据有脏点时把 MSE 换成 MAE 的原因。上面的滑块可以直接验证。

严格一点：什么才配叫「范数」

范数必须满足三条：非负性（‖x‖ ≥ 0，仅零向量为 0）、 齐次性（‖c·x‖ = |c|·‖x‖）、 三角不等式（‖a+b‖ ≤ ‖a‖ + ‖b‖，绕路不会比直达更短）。

第三条是门槛：只有 p ≥ 1 时才成立。所以「L0.5 范数」严格讲不是范数。 同理「L0 范数」（数非零元素的个数）也不是——它违反齐次性。 这个 L0 后面还会出现一次，因为它其实是我们最想要的东西，可惜没法优化。

带着往下走：我们有了旋钮 p。 但「L1 和 L2 到底差在哪」目前还只是公式上的差别，摸不着。 下一节把每一档旋钮直接画成一个图形——这是全文唯一需要真正记住的东西。

02

每种算法有一个形状

铺垫 2 / 2

这是全文唯一需要背下来的一张图。铺垫到此结束。

上一节拿到了旋钮 p。现在的问题：怎么把一档旋钮变成看得见的东西？

办法很简单：把所有「大小恰好等于 1」的向量找出来，看它们围成什么图形。

在平面上试。用 L2 时条件是 x² + y² = 1， 得到一个圆；用 L1 时条件是 |x| + |y| = 1， 满足它的有 (1,0)、(0,1)、(0.5,0.5)……连起来是一个菱形； 用 L∞ 时条件是 max(|x|,|y|) = 1，得到一个正方形。

这个集合叫单位球（unit ball）。它是一把尺子的可视化身份证： 选了哪个 p，就等于选了哪个形状。

顺带解释：p < 1 时为什么不算范数

把滑块拖到 p 小于 1，图形会向内凹陷成星形。 凹陷意味着可以找到两个点，它们的连线跑到图形外面去—— 也就是「绕个路反而更近」，三角不等式被打破。这就是 01 节那条门槛的几何样子。

03

插曲：顺手拿下距离度量

插曲 · 低成本

曼哈顿、欧式、切比雪夫——三个听起来很正式的名字，其实一行公式就讲完了。

这一节和主线关系不大，但它能顺便验证 02 节那张图是对的。读完就回主线。

distance(a, b) = ‖a − b‖ₚ 先算差向量，再量它的大小。选哪个 p，就叫哪个名字。

就这样。曼哈顿距离 = p 取 1， 欧式距离 = p 取 2， 切比雪夫距离 = p 取 ∞，闵可夫斯基距离 = 通用形式。 没有一个是新概念。

从 A(1,2) 到 B(4,6)，差向量是 (3,4)， 三个读数是 7、5、4。它们对应三种走法：

同一段路，三种走法

为什么恰好是 7 > 5 > 4？因为 02 节那三个形状是层层包含的： 菱形 ⊂ 圆 ⊂ 正方形。球撑得越胖，就有越多的点被算作「大小 ≤ 1」， 同一个向量的读数自然越小。所以对任何向量都恒有 ‖x‖∞ ≤ ‖x‖₂ ≤ ‖x‖₁，没有例外。

换成走路的说法一样直观：限制越少，走得越省。 出租车只能横竖走，所以最费；国王能斜着一步顶两步，所以最省。 「短的那一维免费」是切比雪夫最好记的特征——横向差 3、纵向差 4， 国王先斜走 3 步（横向走完、纵向顺带推进 3），再直上 1 步，共 4 步 = max(3,4)。

实际怎么选，以及一个高维陷阱
  • 欧式：默认。K-means、KNN、相似度计算。要求量纲一致， 不标准化的 KNN 是经典事故。
  • 曼哈顿：维度很高、或各维含义独立不可比时更稳。
  • 切比雪夫：只关心「最坏的那一维」，如公差检测、xy 可同时移动的机械臂。

高维陷阱：维度上千时所有点的欧式距离趋于相同（维度灾难）， 「最近邻」失去意义。对策是降维，或换成余弦相似度——它量的是方向而非长度。

插曲结束，回到主线。 注意刚才只用掉了 02 节的一半信息（形状的胖瘦）。 「菱形有角」那一半还没动过。接下来两节就是为它准备的。

04

第二个用途：管住权重

主体 1 / 2

这次量的不是两点之间的距离，而是模型权重向量自己的大小。

02 节留下的「角」还没用上。要用上它，先得知道正则化在做什么。

先看现象：过拟合的模型，权重会失控

模型为了迁就训练集里的噪声，往往会把某些权重推到很极端的值—— 一正一负互相抵消，在训练集上完美，换一批数据就崩。 权重的绝对值大小，是过拟合程度的一个可观测代理。

既然它可观测，就把它加进损失函数，让优化器在追求拟合的同时不得不控制权重规模：

L1 正则（Lasso） 总损失 = 原损失 + λ·‖w‖₁ = 原损失 + λ·Σ|wᵢ| L2 正则（Ridge） 总损失 = 原损失 + (λ/2)·‖w‖₂² = 原损失 + (λ/2)·Σwᵢ² λ 是你调的旋钮：λ=0 就是不正则；λ 越大，模型越保守。

注意 L2 用的是范数的平方，不是范数本身。这不是笔误： ‖w‖₂ 里有个根号，在原点不可导，求导后形式也很丑。 平方掉之后求导得到干净的 λw—— 而正是这个 λw，造就了 L2 的全部性格，下一节会看到。

λ 不是越大越好。 它控制的是偏差与方差的权衡：λ 太小 → 权重放飞，过拟合（方差大）； λ 太大 → 权重被压得太狠，模型学不动，欠拟合（偏差大）。 λ 是超参数，只能靠交叉验证选，没有默认好值。

带着往下走： 上面那两个式子看起来差别很小——一个加绝对值，一个加平方。 凭什么行为会天差地别，一个能归零、一个不能？ 下一节给出两个互相独立的证明。

05

稀疏性：先看见，再算出来

主体 2 / 2 · 全文重心

同一个结论，一个几何证明加一个代数证明。看完就能回答开头那个问题。

04 节的问题：加绝对值和加平方，凭什么行为天差地别？

第一步：先把 λ 换个说法

要画图，得先跨过一个坎——「加惩罚项」和「划活动范围」其实是同一件事。

下面这两个问题，对每一个 λ 都能找到一个 t 使它们的答案完全相同（反之亦然）：

罚项形式 最小化 原损失 + λ‖w‖ₚ ← 04 节用的写法 约束形式 最小化 原损失，但要求 ‖w‖ₚ ≤ t ← 接下来画图用的写法 这是拉格朗日对偶。对应关系很直观：λ 越大 ⟺ t 越小，两者都表示「管得越严」。

为什么要换？因为约束形式里出现了 ‖w‖ₚ ≤ t—— 这正是 02 节那个单位球，只不过半径从 1 变成了 t。 于是权重的活动范围变成一个看得见的菱形或圆， 可以直接画出来。

第二步：几何证明 —— 椭圆会先撞上角

把两样东西叠在一起：椭圆是原损失的等高线（中心是完全不加正则时的最优解）， 彩色区域是权重被允许待的地方。最终的解，只能是两者第一次相碰的那个点。

把 t 拖到 1.2 以下，L1 的解会「粘」在坐标轴上不动——那就是稀疏。

为什么椭圆总是先碰到角？因为角是「凸出来」的部分，离原点最远。 等高线从中心往外扩张时，它更可能先够到伸得最远的地方—— 而菱形伸得最远的四个点，恰好都在坐标轴上（02 节那句话）。 落在坐标轴上，就意味着另一个坐标精确等于 0，那个特征被彻底剔除。

圆没有角，处处一样远，碰撞点由椭圆的朝向随机决定， 落在坐标轴上的概率是零。所以 L2 永远不会归零。

第三步：代数证明 —— 恒定拉力 vs 递减拉力

几何图很有说服力，但它只画了二维。换个角度再证一次：把问题缩到一维， 只有一个权重 w，数据希望它等于 a，惩罚希望它靠近 0。

L1： 最小化 ½(w − a)² + λ|w| 惩罚项导数 = λ·sign(w) ← 恒定拉力，与 w 多大无关 L2： 最小化 ½(w − a)² + ½λw² 惩罚项导数 = λ·w ← 拉力正比于 w，w 越小拉力越小

分歧就在这里。L2 的拉力在 w → 0 时自己先消失了， 所以它永远推不到 0，只能无限逼近。而 L1 的拉力是恒定的 λ， 哪怕 w 已经很小它照样使出全力——只要数据那边的力量小于 λ，w 就被压到 0 并钉在那里。

四个权重，同时施加惩罚

四个特征的原始最优值是 0.2 / 0.5 / 1.0 / 2.0。拖动 λ，看两种正则各自把它们变成什么。

0.50
L1 的解（软阈值 soft-threshold） w* = sign(a) · max(|a| − λ, 0) L2 的解（按比例收缩） w* = a / (1 + λ) λ = 0.5 时：a = 0.5 → L1 给出 0（砍掉），L2 给出 0.333（保留）。这两个公式都能笔算。
L1 · 一刀切

所有权重减去同一个固定量 λ，减到 0 就停。 小于 λ 的直接归零 → 稀疏。
代价：留下来的权重也被压小了 λ，引入偏差。

L2 · 按比例

所有权重乘以同一个比例 1/(1+λ)。 大的减得多、小的减得少，没有一个会变成 0。
好处：解稳定、连续、处处可导。

最后补一句：为什么不直接数「有几个非零」？ 那个函数叫 L0，才是我们真正想要的目标。但它是个阶梯函数—— 权重从 0.001 变到 0.002，非零个数纹丝不动，导数恒为 0；到了 0 那点又直接跳变。 不可导，梯度下降完全没法用。

L1 是最接近 L0 而又保持凸性和可优化性的那个选择： 在所有 p ≥ 1 的范数里，只有 p = 1 的单位球还带着角。 再往下 p 就不是范数了，往上角就被磨圆了。L1 卡在可优化性的边界上，这就是它特殊的全部原因。

开头那个问题，现在可以回答了： 因为 L1 的单位球是菱形，菱形有角，角落在坐标轴上，落在坐标轴上就意味着某个权重精确为 0。 L2 的单位球是圆，圆没有角，所以做不到。剩下的只有工程问题了。

四个真正会翻车的坑

坑一：忘了先标准化特征

惩罚项对所有权重一视同仁，但一个以「元」为单位的特征和一个以「万元」 为单位的特征，权重天然差 10000 倍。不标准化，正则化就会莫名其妙地重罚某些特征、放过另一些。 距离度量同理——这是 KNN 和 K-means 最常见的事故来源。

坑二：把偏置项 b 也一起惩罚了

正则化的目的是限制模型对输入的敏感程度，而偏置只是整体平移， 不影响函数复杂度。惩罚 b 会强迫输出往 0 靠，引入无谓偏差。主流框架默认不惩罚 bias。

坑三：以为「防过拟合」和「特征选择」是 L1 的两个功能

是一件事的两种说法。L1 通过把部分权重压到 0 来降低模型的有效复杂度—— 这既是特征选择，也正是它防止过拟合的方式。不是并列的两个功能。

坑四：特征高度相关时直接上 Lasso

Lasso 会在一组相关特征里随机挑一个留下、其余归零，换个随机种子结果就变。 如果你要把选出的特征拿去做业务解读，这个不稳定性会很致命。

对策是 Elastic Net：惩罚项写成 λ₁‖w‖₁ + λ₂‖w‖₂²，同时拿到 L1 的稀疏性和 L2 的稳定性， 让相关特征抱团进出。sklearn 里就是 ElasticNet。

补充：神经网络里的 weight decay 就是 L2

把 (λ/2)‖w‖₂² 加进损失，梯度多出一项 λw，更新式变成：

w ← w − η(∂L/∂w + λw) = (1 − ηλ)·w − η·∂L/∂w

每一步先把权重乘以一个略小于 1 的数，再做正常更新—— 「衰减」这个名字就是这么来的。（严格说 AdamW 里的 weight decay 与 L2 正则不完全等价， 因为自适应学习率会把 λw 一起缩放，AdamW 的改动正是把它拆出来单独处理。）

全文一句话： 选一个 p，就是选一个形状。 把这个形状套在两点之差上，叫距离；套在权重向量上，叫正则化。 菱形有角、角在坐标轴上，所以 L1 能把权重压到精确的 0； 圆没有角，所以 L2 只能让权重整体变小。其余全是推论。
