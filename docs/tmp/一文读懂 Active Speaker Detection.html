01 · capability contract

ASD 的契约：给每条人脸轨道打“正在说话”分数

真实输入不是一张图，而是一段视频：同一时刻可能有多人露脸，声音可能来自其中一人、多人、画外人或背景。ASD 把视频变成一组带时间的判断。

✓ 交给 ASD 的事

  • 逐帧/逐片段判断：某个可见 face track 当前是否 speaking。
  • 绑定音频和人脸：不是只听见声音，而是判断这张脸是否和声音同步。
  • 产出时间段：为剪辑、会议分析、speaker diarization、视频索引提供 active speaker segments。
  • 处理多人同屏：每个人脸都是一个候选，可能一人、多人或无人活跃。

✗ 不该指望 ASD 的事

  • 识别身份：ASD 不回答“这是张三吗”，那是 speaker/face recognition。
  • 转写内容：它不输出文字，ASR 才负责 speech-to-text。
  • 理解语义：点头、表情、语气、话题理解是下游任务。
  • 看不见也定位：说话人不露脸时，ASD 应该输出“无可见活跃说话人”，不是强行分给某张脸。
一句话心智模型：VAD 问“有没有人声”，ASD 问“这张脸是不是当前声音的来源”。它是音频时间轴和视觉人脸轨道之间的绑定问题。工程上最好把 active / inactive / uncertain 都当成合法输出，低置信段不要硬判。
02 · neighboring tasks

先和邻近任务切开：ASD 不是 VAD，也不是 diarization

任务核心问题典型输入输出和 ASD 的关系
VAD
Voice Activity Detection		这段音频里有没有人声audio → speech / non-speechASD 常用它作为音频先验，但 VAD 不知道屏幕上是谁。
Speaker Diarization谁在什么时候说话audio → speaker A/B/C segmentsdiarization 不需要人脸；ASD 可为视频场景提供可见人脸约束。
Speaker Recognition这是不是某个已知人voice embedding → identityASD 判断是否活跃，不判断身份。两者可组合成“某人何时露脸发言”。
Lip Reading / AVSR嘴在说什么内容face crop + audio → textASD 只需二分类，通常不需要理解词语。
Face Tracking同一个人脸如何跨帧连接frames → face tracks这是 ASD 的前置条件，track 断裂会直接造成说话段断裂。
03 · input to output

流水线：不是“识别一个人”，而是给每条 face track 打分

成熟 ASD 系统一般不是一个裸模型直接吃整段视频。工程上会先把视频拆成轨道和窗口，再让模型判断每个候选。

01

解码与采样

统一 fps、音频采样率和时间戳，避免音画错位。

02

人脸检测

每帧找出可见人脸，得到候选框。

03

Face tracking

把同一人的脸跨帧连成 track。

04

音频窗口

截取和当前帧对齐的短音频片段，提取声学特征。

05

AV 融合

比较嘴部运动、脸部动态、音频能量和同步关系。

06

平滑成段

阈值、最短持续时间、重叠说话策略，输出 segments。

最常见的工程错误：把模型分数当最终结果。生产里要保留 raw score、track id、时间戳、阈值版本和后处理规则，否则误判无法复盘。
04 · mechanism

模型怎么做判断：三类证据，缺一类都会出错

ASD 不是简单“嘴动 = 说话”。成熟模型会把音频、视觉和时间上下文一起看。

四个反例把边界讲清楚

画外音

音频很强，但所有脸都不同步。正确输出应是“屏幕上无人活跃”，不是找一个最像的人。

嘴在动但没出声

人可能咀嚼、笑、低声旁聊或被静音。视觉证据强，音频/同步证据弱。

多人同时说话

不是单选题。会议抢话、合唱、争论时可能多个 face track 同时 active。

音画不同步

转码延迟、远程会议延迟、配音片会破坏同步线索，需要数据与后处理兜住。

05 · evolution

演进过程：从“嘴和声音同步吗”到“长上下文里的多人绑定”

ASD 的发展主线不是单纯换网络，而是不断补齐真实视频里的缺失证据：数据集、长时序、多人关系、轻量部署和鲁棒性。

早期

音画同步
用嘴部运动和音频同步性判断“这张嘴是不是这段声音”。适合干净单人或少人场景。

2019-2020

AVA-ActiveSpeaker
大规模带 face track 的帧级标注让 ASD 有了主流 benchmark。

2021

TalkNet / ASW
长短期音视频证据与野外数据集推动模型离开“瞬时判断”。

2022

ASDNet / SPELL
注意力、图结构和长时空关系开始显式建模多人场景。

2023-2024

Light-ASD / LoCoNet / TalkNCE
轻量部署、长短上下文、对比学习成为成熟路线。

2025+

鲁棒性与跨域
唇部 landmark、噪声场景、跨域视频和对抗鲁棒性成为新焦点。

06 · mature solutions

目前成熟方案：按业务约束选，不是只看榜单最高

路线代表强项适合场景注意点
经典 AV 融合AVA baseline、TalkNet心智清楚，音频/视觉/时序证据完整研究复现、离线分析、对准确率有要求的基线依赖稳定 face track 和较干净的同步信号。
轻量部署Light-ASD / LRASD参数和 FLOPs 更低，适合边缘或批处理大量会议视频、在线预处理、预算有限的服务极端多人复杂关系可能不如上下文模型。
多人上下文SPELL、LoCoNet把同人长时序和同帧多人关系纳入判断多人访谈、圆桌会议、综艺、镜头内多人互动实现复杂度和数据预处理要求更高。
表征/鲁棒增强TalkNCE、LASER改善音画错配、噪声、低质视频下的泛化野外视频、社媒视频、跨域部署新方法要用自有数据验证，不能只看 AVA 分数。
系统组合ASD + VAD + diarization + ASR从“谁在说”扩展到“谁说了什么”会议纪要、视频检索、自动剪辑ASD 不是最终产品，后面还要接身份、转写、审核。
实用建议：不知道从哪开始，就用 TalkNet/Light-ASD 级别的可复现基线跑通数据流；多人复杂场景再看 LoCoNet/SPELL；部署前一定用自己的业务视频做误判集。
07 · post-processing

后处理决定“能不能用”：阈值、平滑和业务规则

阈值不是固定真理

高阈值减少误报，但会漏掉小脸、侧脸、低声发言；低阈值提高召回，但画外音和嘴动误报会增加。

短段要合并或过滤

单帧分数会抖动。通常需要最短发言时长、最大间隙合并、track 断裂修复。

允许重叠说话

会议抢话时不能强制 one-hot。业务若只需要主说话人，可以再用分数最高者做二次选择。

保留“不确定”

低置信段不要硬判，进入人工复核或下游弱标签，质量比表面自动化更重要。

08 · evaluation

验证方式：不要只看 demo，要按错误类型验收

ASD 常用 frame-level mAP、precision、recall、F1 等指标。但上线更关心“哪些错误能接受”。

离线评估

  • 按 face track 的每帧标签算 mAP / AP。
  • 按 segment 检查起止时间偏差。
  • 分桶看小脸、侧脸、噪声、多人、画外音。
  • 保留误判样本，作为下一版回归集。

人工抽检

  • 每个视频抽高置信、低置信、边界段。
  • 优先看模型分歧、短段密集、多人重叠。
  • 用可视化页同时展示脸框、波形、分数曲线。
  • 标注“不确定/不可判”，不要逼标注员二选一。
TP可见人脸确实在说话，模型判 active
FP画外音、嘴动或噪声导致误判 active
FN小脸、遮挡、低声、侧脸导致漏检
TN无人说话或非说话脸被正确排除
09 · failure modes

常见误区：把 ASD 当成万能“说话理解器”会出问题

误区 1：有声音就一定有人 active

旁白、背景电视、电话外放、配音片都可能只有 audio，没有可见 active face。

误区 2：嘴动就是在说话

吃东西、笑、跟读、无声练习会产生视觉运动，但不是当前音频来源。

误区 3：ASD 可以替代身份识别

ASD 输出 track id 上的 speaking score，不保证知道这个人是谁。

误区 4：榜单分数等于业务可用

会议、短视频、直播、影视剧的噪声和剪辑方式不同，必须用自有样本验证。

10 · deployment

落地路线：先定义“最终消费的时间段”，再选模型

业务ASD 输出怎么用策略质量门槛
会议视频发言人时间轴、自动切镜、纪要对齐ASD + diarization + ASR；允许重叠说话不能把画外音错分给参会者；边界误差要可控。
访谈/综艺剪辑自动找发言镜头和反应镜头高召回优先，再人工审剪宁可多给候选，不要漏掉关键发言。
数据清洗筛出可见说话人片段训练 AV 模型高精度优先，低置信丢弃片段必须人脸清楚、音画同步、标签干净。
实时产品当前说话人高亮、摄像头追踪轻量模型 + 短窗口 + 平滑延迟和稳定性优先，允许短暂滞后。

EOF · cheat sheet

带走这六句话

定义

ASD 判断每个可见 face track 在某个时间是否正在发出当前可听见的声音。

主线

音频告诉你“有声”，视觉告诉你“哪张嘴在动”，同步和上下文告诉你“是不是同一个事件”。

边界

它不识别身份、不转文字、不理解语义，也不能定位画外不可见说话人。

成熟方案

TalkNet/Light-ASD 可做基线；多人复杂场景看 LoCoNet/SPELL；跨域噪声看鲁棒增强。

验证

按误报、漏报、重叠说话、小脸侧脸、画外音分桶评估，不只看平均分。

落地

保留 raw score 和最终 segment 两层结果，让阈值、平滑和人工复核都可回溯。
