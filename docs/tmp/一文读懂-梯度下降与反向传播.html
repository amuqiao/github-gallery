00

先把问题变小到能手算

所有抽象概念都会落在这一个例子上。它小到你可以用笔算完，又完整包含了训练的每个环节。

手上有三条数据，看起来是一条过原点的直线：

数据（永远不变）
x真实值 y
12

36
模型（两个可拧的旋钮）
ŷ = w·x + b

w 是斜率，b 是截距。训练要回答的唯一问题是： 这两个旋钮该拧到多少？
（答案显然是 w=2, b=0，但我们要装作不知道，看机器怎么摸出来。）

这里有一次容易被忽略的角色互换。 看 z = x² + y² 这种式子时，人会本能地觉得 x、y 是"喂进去的数据"。 在训练场景里正好相反：数据一旦给定就是常数，参数 w、b 才是自变量。 后面所有的"求导"，都是对参数求导，不是对数据求导。

把这个认知转过来之后，整篇文章的主线就清楚了：我们要构造一个函数 L(w, b)，输入是两个旋钮的位置，输出是"错得多离谱"。 它的图像就是一座山，训练就是下山。

01

损失函数：把"错得多离谱"压成一个数

它的产出是一个标量。这个看似平淡的要求，决定了后面所有事情的形态。

为什么必须是"一个"数

模型在三条数据上各犯了一点错。要判断"旋钮拧过之后是变好还是变坏"， 就必须能比大小；能比大小的东西只能是单个数字。于是把三个误差平方后相加：

L(w, b) = (w·1+b−2)² + (w·2+b−4)² + (w·3+b−6)² └── 第一条数据的误差 └── 第二条 └── 第三条

展开后是一个关于 w、b 的二次函数——它的图像是一个开口向上的碗， 也就是页面顶部那张等高线图。损失函数的第一个作用，是把"调参"这件模糊的事， 变成一个有明确地形的搜索问题。

第二个作用：它是你写下的价值观

为什么是平方，不是绝对值？这不是数学规定，是你在定义什么叫"错得严重"。 下面这张图里拖动误差大小，看三种损失对同一个误差的态度差多少：

模型会严格照着你写的标准去优化，包括你写错的部分。 如果癌症筛查里漏诊和误诊的代价被写成一样，模型就会认真地把它们当成一样重要—— 并且一路报告"损失在下降"。指标选歪了，训出来的东西就歪了。

第三个作用（也是入场券）：它必须可导

这一点解释了一个高频困惑：我关心的明明是准确率，为什么不直接优化准确率？

准确率：几乎处处零导数

模型输出 0.40，你把权重挪一点变成 0.41——分类结果还是"否"，准确率纹丝不动。 导数为 0，等于告诉优化器"你怎么动都无所谓"，寸步难行。

交叉熵：处处有坡度

同样从 0.40 挪到 0.41，损失会诚实地降低一点点。有了这一点点， 优化器才知道往哪走。

所以真实情况是：我们想要的目标（准确率）不可导，只好去优化一个可导的替身， 指望替身降下来时真目标跟着涨。这个替身在术语里叫 surrogate loss。 可导性不是损失函数的附带属性，而是它的入场券——这也是为什么 ReLU、softmax 这些设计里处处在小心维护可导性。

顺带分清：损失函数 ≠ 评估指标
损失函数评估指标
给谁看优化器人 / 业务方
硬要求必须可导不需要可导
例子MSE、Cross-Entropy准确率、F1、AUC、召回率
角色训练时的方向盘最终验收标准

两者经常不同步：损失还在降但准确率不动了； 或者训练损失降了、线上效果反而变差（过拟合）。 判断模型好坏看指标，驱动模型改变的是损失。

02

导数与偏导数：地形有了，怎么知道脚下的坡

导数的本体是「变化率」，不是「求极值的工具」。先把这句话坐实，后面梯度下降才不会理解偏。

导数 = 自变量动一点点，因变量动多少

取两个点连一条割线，算它的斜率；然后让两点越靠越近。拖动下面的 h， 看割线怎么变成切线：

从割线到切线 · f(x)=x² 在 x=1 处
1.000
割线斜率 3.000
h 越小，割线斜率越接近 2 —— 这个极限值就是 f′(1)。导数是一个局部的量：它只描述这一点附近的陡峭程度。

注意这里根本没提"极值"。导数在绝大多数场合用的是它的数值： 位置求导得速度、成本求导得边际成本、房贷对利率求导得敏感度。 "导数为零对应极值"只是它众多推论中的一条，而深度学习恰恰主要用数值，不用零点。

偏导数：多个旋钮时，一次只动一个

我们的 L(w, b) 有两个自变量，"坡度"就不再是一个数了—— 站在山坡上，朝东和朝北的陡峭程度可以完全不同。偏导数的定义就是： 把其他所有变量锁死，只拧一个，看损失变多少。

右图那条橙色切线的斜率，就是 ∂L/∂w。换一个 b，截面曲线的形状和位置都会变——这正是"偏导数依赖于你站在哪里"的含义。

对我们的例子把两个偏导数算出来，全文后面都要用它们：

∂L/∂w = 28w + 12b − 56 ← 只拧 w，损失的变化率 ∂L/∂b = 12w + 6b − 24 ← 只拧 b，损失的变化率

梯度就是把所有偏导数排成一列。 ∇L = (∂L/∂w, ∂L/∂b)。它是一个向量， 有方向也有长度：方向指向上坡最陡的那一边，长度代表有多陡。 在真实模型里这一列有上亿个分量，但含义完全一样。

为什么梯度方向恰好是"最陡上坡"？

沿任意单位方向 u 走，损失的变化率是方向导数 ∇L · u。点积在 u 与 ∇L 同向时取最大值、反向时取最小值。所以：

  • 朝 +∇L 走，损失涨得最快；
  • 朝 −∇L 走，损失降得最快 —— 这就是梯度下降里那个负号的全部来历。

顺带一提：梯度处处垂直于等高线。你在页面顶部那张图里看到的 每一步轨迹，都是与椭圆等高线正交的。

03

梯度下降：不解方程，一步一步走出来

这一节是全文的核心。下面这个面板算的是真实数值，不是示意——你可以拿笔核对每一步。

课本教的求极值方法是：令所有偏导等于 0，解方程组。对我们这个两参数的例子确实解得出来。 但真实模型有上亿个参数，那个方程组没人解得动。于是换一个笨办法：

w ← w − η · ∂L/∂w η (eta) 叫学习率，是你迈步的大小 b ← b − η · ∂L/∂b

翻译成人话：看一眼脚下哪边是下坡，朝那个方向挪一小步，然后重新看一眼。 梯度在这里扮演的不是"零点判据"，而是方向盘。

之字形不是 bug，是地形的锅。 这个例子的碗是狭长椭圆而不是正圆——两个方向的陡峭程度差了 46 倍。 梯度永远垂直于等高线，在狭长山谷里它几乎横着指向对岸，而不是指向碗底。 真实深度学习模型的曲面比这病态得多，这正是 Momentum、Adam 这类优化器要解决的问题： 它们本质上都是在修正"梯度方向≠通往最低点的方向"这件事。

两个偏导都是负数，说明"往 w 增大、b 增大的方向走是下坡"， 减去负数正好让它们变大。负号在这里的作用一目了然。

η 太小

收敛慢，浪费算力；还容易困在一个不够好的地方出不来。

η 太大

震荡甚至发散。loss 变成 NaN 时，第一个该怀疑的就是它。

实践中

先用较大的 η 快速下降，再逐步调小（learning rate schedule）。

04

反向传播：不是新算法，是把偏导数算得起

梯度下降告诉你「拿到梯度之后怎么办」。反向传播回答的是另一个问题：这上亿个偏导数，到底怎么算出来。

先看笨办法有多贵。想知道 ∂L/∂w₃₇，可以把 w₃₇ 拧一点点， 跑一遍整个网络看 loss 变多少。可行，但一亿个参数就要跑一亿遍前向传播—— 一次训练迭代要算到天荒地老。

反向传播的贡献是：用一次前向 + 一次反向，把所有参数的偏导数一次性全部求出。 靠的就是链式法则。

交互演示 · 计算图

一个只有两层的迷你网络

前向算出预测和损失，反向逐层把"责任"分回去。点按钮一步步看。

链式法则在这里的直觉

想知道 w₁ 该负多少责任，得问一串问题：

w₁ 动一点 → h 动多少？ ∂h/∂w₁ = x h 动一点 → ŷ 动多少？ ∂ŷ/∂h = w₂ ŷ 动一点 → L 动多少？ ∂L/∂ŷ = 2(ŷ−y) 把这三段乘起来： ∂L/∂w₁ = ∂L/∂ŷ · ∂ŷ/∂h · ∂h/∂w₁

关键在于「从后往前」这个顺序。算 ∂L/∂w₁ 时， 中间那一段 ∂L/∂h 在上一步已经算过了，直接拿来用即可。 每往前一层，只需要乘上本层的局部导数。这就是"反向"两个字的含义—— 从损失开始往回推责任，路上的中间结果全部复用。

一个很漂亮的巧合。 MSE 对预测值求导，结果正好是 2(ŷ − y)，也就是误差本身。 所以"误差"这个词在数学上不是比喻——反向传播最开始往回送的那个东西，字面意义上就是误差。

三个常被搞混的关系
名字它到底是什么不是什么
Backpropagation 高效计算所有 ∂L/∂w 的方法 不是优化算法，它不负责更新参数
Gradient Descent 拿到梯度后怎么更新参数的规则 不关心梯度是怎么来的
Chain Rule 微积分里的数学定理 不是深度学习发明的

一句话串起来：链式法则是数学工具，反向传播是用它做的高效实现， 梯度下降是拿到结果之后的动作。三者是接力关系，不是同一层的东西。

梯度消失 / 梯度爆炸，从这里就能看出来

既然每往前一层要乘一次局部导数，那么 100 层网络的 ∂L/∂w₁ 就是 100 个数连乘。

  • 每个都是 0.5 → 0.5¹⁰⁰ ≈ 8×10⁻³¹，前面的层几乎收不到信号：梯度消失。
  • 每个都是 1.5 → 1.5¹⁰⁰ ≈ 4×10¹⁷，参数一步飞到天上：梯度爆炸。

ReLU（导数是 1 而非 0.几）、残差连接（给梯度一条直达通路）、 LayerNorm、梯度裁剪，全都是在治这个连乘问题。理解了链式法则的乘法结构， 这些设计就不再是需要背的名词。

05

什么时候能停：一阶只是嫌疑，二阶才定性

梯度为零的地方不一定是碗底。这一节讲清楚二阶导数在理论上做什么，以及为什么实践中几乎不用它。

一阶导数负责找"平地"，二阶导数负责鉴定这块平地的性质。 梯度为零的点统称驻点（stationary point），它可能是三种东西之一：

极小值 · 碗底

两个方向都向上凹。这是我们想要的。

极大值 · 山顶

两个方向都向下凸。梯度下降不会停在这。

鞍点 · 马鞍

一个方向凹、一个方向凸。高维空间里的常客。

只测 x、y 两个方向是不够的

这是最容易踩的坑。看这个函数在原点：

z = x² + y² + 4xy ∂²z/∂x² = 2 > 0 x 方向说：向上凹 ∂²z/∂y² = 2 > 0 y 方向说：向上凹 但它是一个马鞍面 —— 沿着 y = −x 这条 45° 方向走，函数一路往下掉。

两个方向都报"碗"，实际却是马鞍。原因是过一个点有无穷多个方向， 你只量了正交的两条。补上的那个量叫混合偏导 ∂²z/∂x∂y， 它测的是扭曲：沿 y 方向挪动一点，x 方向的坡度变了多少。 扭曲一旦大过一定程度，就会在斜方向上撬开一条下坡通道。

二元函数的完整判据： 记 A = ∂²z/∂x²，C = ∂²z/∂y²， B = ∂²z/∂x∂y，

  • AC − B² > 0 且 A > 0 → 极小值（碗底）
  • AC − B² > 0 且 A < 0 → 极大值（山顶）
  • AC − B² < 0 → 鞍点

那个 −B² 就是在"扣掉扭曲带来的损失"。 上面例子里 AC − B² = 4 − 16 = −12 < 0，判定为鞍点，和事实吻合。

把这四个二阶偏导排成方阵，就是 Hessian 矩阵。 它的特征值正好是"主方向上的曲率"——也就是曲面在这点最弯和最不弯的两个方向上的弯曲程度。 特征值全正是碗底，全负是山顶，有正有负是鞍点。

我们那个例子的 Hessian： H = [ 28 12 ] 特征值 λ₁ ≈ 33.28, λ₂ ≈ 0.72 [ 12 6 ] 两个都正 → 确实是碗底 顺带解释了 03 节的之字形：λ₁/λ₂ ≈ 46，两个主方向陡峭程度差 46 倍，碗被拉成狭长椭圆。 也解释了发散阈值：稳定要求 η < 2/λ₁ ≈ 0.060，和实验里 0.061 开始飞掉完全对上。

但实践中，这一整套流程几乎从不执行。 参数有一亿个时，Hessian 是 10⁸×10⁸ 的矩阵——光存下来就要 40000 TB，更别说求特征值。 所以真实训练里没人验证自己是不是到了极小值， 大家看的是"验证集损失不再下降就停手"。严谨性让位给了可计算性。

好消息：高维空间里，鞍点比局部极小值更常见，而且没那么可怕

一个驻点要成为局部极小值，需要全部一亿个特征值都是正的。 如果符号大致随机，这个概率低得可以忽略。所以高维损失曲面上的驻点绝大多数是鞍点。

而鞍点是可以逃掉的：只要往那个"向下凸"的方向有一点扰动就能滑走， SGD 的随机噪声天然提供了这种扰动。真正麻烦的反而是大片平坦区域（梯度接近 0 但四周也没坡）， 以及狭长山谷造成的震荡——这两个才是优化器设计的主要战场。

顺带：导数为 0 既不充分也不必要
  • 不充分：y = x³ 在原点导数为 0，但既不是极大也不是极小（是拐点）。
  • 不必要：y = |x| 在 0 处取到最小值，但那里根本没有导数。ReLU 就是这种情况。
  • 还有端点：闭区间上的最值可能落在边界，那里导数不为 0。

所以"令导数为零求极值"严格来说只覆盖开区间内部的可导驻点这一类情况。

六个常见误区

误区一：导数就是用来求极值的

导数的本体是变化率，求极值只是它的一条推论。 速度、加速度、边际成本、敏感度分析、泰勒近似、几乎全部物理定律（微分方程）， 都在用导数而完全不涉及极值。深度学习里也是如此——反向传播算出的偏导数， 本职工作是回答"这个权重动一点点，loss 会动多少"，纯粹的敏感度问题。

误区二：训练是在对数据求导

是对参数求导。数据在训练中是常数。 损失函数写全是 L(w₁, w₂, …, wₙ)，一个有几亿个自变量的多元函数， 坐标轴是旋钮不是特征。（对输入求导也有用，但那是对抗样本、可解释性的领域，不是训练。）

误区三：反向传播是一种优化算法

它只负责算梯度，一个参数都不更新。 更新是优化器（SGD / Adam）的事。把 backprop 换成数值微分，训练照样能跑，只是慢到不可行； 把 SGD 换成 Adam，backprop 那部分一行都不用改。两者是可以独立替换的模块。

误区四：loss 降下去了，模型就好了

训练 loss 降到 0 也可能只是把训练集背下来了。 损失是训练时的方向盘，验证集指标才是验收标准。 两者背离（训练 loss 降、验证 loss 升）就是过拟合的典型信号。

误区五：梯度指向最低点

梯度指向的是当前位置最陡的方向，它是纯局部信息， 对山谷的整体走向一无所知。03 节那个之字形就是证据： 每一步都严格朝着"当下最陡"走，合起来却在来回横跳。 Momentum 做的事，本质上就是给这条路径加上惯性，把横向的来回抵消掉、把纵向的前进累加起来。

误区六：得先找到全局最小值

不需要，也做不到。深度学习的损失曲面几乎从来不是碗状， 全局最小值既找不到也无法验证。实践中要的只是"一个泛化得足够好的解"， 而经验表明大部分局部极小值的效果彼此差别不大。 训练的目标是拿到一个能用的模型，不是解一道数学题。

如果只能记住一句话： 损失函数把"好坏"变成一座山，反向传播算出脚下每个方向的坡度， 梯度下降照着最陡的下坡方向迈一步——然后重复几十万次。 二阶导数在理论上负责鉴定碗底，在实践中被"验证集不再改善就停"取代了。
