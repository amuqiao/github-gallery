SECTION 01

先理解：激活函数到底在“激活”什么

把一个神经元拆开看，它只做两件事。第一步是线性打分：z = wx + b（多维时是 z = w·x + b）。这一步在回答“输入和我关心的方向有多对齐”，输出是一个可以任意大、任意小的实数。第二步才是激活：a = f(z)。它把这个裸的打分整形成适合往下一层传递的表示——这就是“激活”的含义：决定这个神经元以什么强度、什么形态参与后面的计算。

所以激活函数同时干了三件事，理解任何一个具体函数，都可以回到这三个维度上：

① 引入非线性

让“层的叠加”产生新的表达能力。没有它，加深网络在数学上是无效的（下面马上证明）。

② 控制范围与分布

把无界的打分压到 (0,1)、(−1,1)，或砍掉负半轴。这决定了下一层收到的输入长什么样、是否零中心。

③ 塑造梯度

反向传播时梯度要乘上 f′(z)。函数在哪里平、在哪里陡，直接决定训练信号能不能穿过这一层。

前两点在首屏就能看到：切到 Sigmoid，无论怎么拖 w，输出都被关在 (0,1) 里；切到 ReLU，把 z 拖到负半轴，输出和导数同时归零。第三点是第 4 节的主角。

一个两行的推导：为什么“堆线性层”是无效的

假设我们不用激活函数（或者说 f(z)=z），直接堆两层线性层：

h = W1x + b1
y = W2h + b2 = W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2) = W′x + b′ 两层的参数合并成了一个新的 W′ 和 b′——整个网络精确等价于一层线性变换。归纳下去，一百层也一样。参数变多了，但函数空间没有变大：它永远只能画直线（超平面）。

这就是为什么说激活函数不是网络里的一个“配件”，而是让深度成立的前提。非线性 f 插在层与层之间，让 W₂ f(W₁x+b₁) 无法再合并——每一层才真正贡献了新的表达能力。眼见为实：下一节你可以亲手训练一个小网络，看看拿掉激活函数会发生什么。

SECTION 02

非线性为什么是深度学习的核心

“深度”的价值不在于层数这个数字，而在于非线性特征的逐层组合：第一层用非线性把输入空间折出几个简单的弯，第二层把这些弯组合成更复杂的形状，层层递进。ReLU 网络是个直观的例子——每个 ReLU 神经元在输入空间里画出一条折痕，多层组合后就能用大量小平面拼出任意复杂的曲面。拿掉非线性，所有折痕消失，网络退回一条直线。

把打分变成概率：Sigmoid 与 Softmax

Sigmoid二分类输出层的标准答案；作为隐藏层已基本退役
σ(z) = 1 / (1 + e−z) ，输出 ∈ (0, 1) ，σ′(z) = σ(z)(1 − σ(z)) ≤ 0.25 它把任意实数打分平滑地压进 (0,1)，天然可以解释为“正类概率”，配 Binary Cross Entropy 时梯度形式还特别干净（就是 σ(z) − y）。这是它守住输出层位置的原因。

但作为隐藏层它有三个问题，且互相叠加：① 饱和——|z| 稍大（比如 5）导数就趋近 0，这一层几乎不再学习；② 导数上限只有 0.25——链式法则逐层相乘，信号指数级衰减（第 4 节演示）；③ 非零中心——输出恒为正，下一层收到的输入全是正数，同一神经元所有权重的梯度被迫同号，更新方向只能走“之字形”，收敛变慢。

输出层：二分类 / 多标签门控（LSTM/GRU）隐藏层：梯度消失非零中心
Softmax不是普通激活——它是多分类输出的归一化器，作用在整个向量上
softmax(z)i = ezi / Σj ezj ，输出 ∈ (0,1) 且 Σ = 1 前面所有函数都是逐元素的：一个 z 进，一个 a 出。Softmax 不同——它读入整个 logits 向量，让各类别通过指数放大互相竞争，输出一个和为 1 的概率分布。改动任何一个 logit，所有输出都会变。

因此它只出现在互斥多分类的输出端（以及 attention 权重这类“归一化竞争”场景），不用于普通隐藏层：隐藏层需要的是独立的特征检测器，而 Softmax 会强行让特征互相抢份额，还把梯度耦合在一起。它与 Sigmoid 的输出层分工见下面的对比卡片。

零中心的压缩：Tanh

TanhSigmoid 的零中心版本；RNN 时代的隐藏层主力
tanh(z) = (ez − e−z) / (ez + e−z) = 2σ(2z) − 1 ，输出 ∈ (−1, 1) ，tanh′(z) = 1 − tanh²(z) ≤ 1 本质是拉伸平移过的 Sigmoid。两个改进：输出零中心，下一层拿到的输入有正有负，消除了之字形更新问题；导数上限从 0.25 提到 1（仅在 z=0 处取到）。

但它没有解决根本问题：两端照样饱和，深层堆叠时梯度照样消失，只是比 Sigmoid 慢一些。今天它主要活跃在 RNN/LSTM 的状态更新里（状态需要被约束在 (−1,1) 内防止爆炸），以及需要有界对称输出的场合。

让梯度通行：ReLU 与它的修补者们

ReLU现代深度网络的默认起点；用“不压缩”换来了梯度畅通
ReLU(z) = max(0, z) ，导数：z > 0 时为 1，z < 0 时为 0 关键在“正区间导数恒等于 1”：梯度穿过激活层时原样通过，不衰减。链式法则里那串小于 1 的乘数消失了，这是深层网络（配合良好初始化和归一化）能训起来的直接原因之一。

附赠两个好处：稀疏激活——约一半神经元输出 0，表示更解耦；计算极简——一次比较，没有指数运算。代价是那条硬边界：如果某个神经元的 z 在整个数据集上都落进负区（常见诱因：学习率过大把偏置推得太负），它的输出恒为 0、导数恒为 0，梯度再也进不来，永久死亡——这就是 dead ReLU。轻则浪费容量，重则一次糟糕的更新杀掉一大片神经元。

正区梯度 = 1稀疏、便宜dead ReLU非零中心
Leaky ReLU / PReLU / ELU / SELU同一个动机的四种答案：别让负区彻底死掉

这一族不必逐个背公式，记住它们都在修同一个 bug（负区梯度为 0），只是激进程度不同：

  • Leaky ReLU：负区给一个小斜率 αz（α 常取 0.01），梯度永不为零，成本几乎为零。最保守的修法。
  • PReLU：把 α 变成可学习参数，让网络自己决定漏多少。
  • ELU：负区用 α(e^z − 1) 平滑地趋向 −α，输出均值更接近零（顺手改善非零中心问题），但引入了指数运算。
  • SELU：精心调常数的 ELU，配合特定初始化可以“自归一化”（各层激活自动保持均值 0 方差 1）——想法漂亮，但条件苛刻，实践中基本被 BatchNorm/LayerNorm + ReLU/GELU 路线取代。

实用结论：怀疑出现 dead ReLU 时，Leaky ReLU 是成本最低的替换实验；其余变体在现代架构（归一化层普及之后）带来的增益通常很小。

平滑的概率式门控：GELU 与 SiLU/Swish

GELUTransformer 系（BERT/GPT/ViT）的事实标准
GELU(z) = z · Φ(z) （Φ 是标准正态的 CDF）≈ z · σ(1.702z) 读法：把输入乘上“它该被保留的概率”。z 很大 → Φ(z)≈1，几乎全通过；z 很负 → Φ(z)≈0，几乎关闭；中间地带则是平滑加权而非硬切换。它不是 ReLU 那样的硬截断闸门，而是一个带概率意味的软门控。

和 ReLU 的差异在零点附近：ReLU 在 0 处有个不可导的折角、负区一刀切；GELU 处处平滑可导，负区小幅保留信息（曲线在 z≈−0.75 附近还有一个浅浅的下凹），loss 曲面更光滑，深层 Transformer 训练更稳。代价是多一次指数/erf 运算——在以矩阵乘法为主的大模型里可以忽略。详细对比见下方卡片。

平滑可导Transformer 默认略贵于 ReLU
SiLU / SwishGELU 的近亲：自门控 z·σ(z)
SiLU(z) = z · σ(z) 同样的“输入 × 门”结构，只是门从 Φ(z) 换成 σ(z)。曲线与 GELU 几乎重叠（在浏览器里切换两者对比一下），性质也一致：平滑、非单调、负区留一点信息。

两者在实践里近似可互换，选择往往跟随架构惯例：BERT/GPT/ViT 系用 GELU；EfficientNet、YOLO 系以及 LLaMA 等模型的 SwiGLU 门控 FFN 用 SiLU。不必纠结谁更好——差异远小于学习率调错一档。

ReLU vs GELU：硬闸门与软门控 ›

ReLU · 硬截断

  • 门只有开/关两档：z>0 全通过，z<0 全丢弃
  • 正区梯度恒为 1，信号无衰减；负区梯度恒为 0
  • 零点有折角，loss 曲面带棱；存在 dead ReLU 风险
  • 计算最便宜，CNN/MLP 的强基线

GELU · 平滑加权

  • 门是连续的：按 Φ(z) 给每个输入一个 0~1 的通过权重
  • 处处可导，负区保留微弱梯度，不会永久死亡
  • loss 曲面更平滑，深层 Transformer 训练更稳定
  • 略贵（含 erf/exp），大模型中占比可忽略
怎么选：CNN/MLP 先用 ReLU，够用且便宜；Transformer 或很深的网络默认 GELU（或 SiLU）。两者思想同源——GELU 可以理解为“把 ReLU 的 0/1 硬门换成概率软门”。

SECTION 04

梯度消失：从导数看训练为什么变慢

反向传播是链式法则的机械执行。loss 对第 l 层的梯度，要从最后一层出发，逐层乘上“该层激活函数的导数 × 权重矩阵”才能传回来：

∂L/∂hl = ∂L/∂hL · Πk=l+1..L ( WkT · diag(f′(zk)) ) 注意那个连乘号。每往回传一层，梯度就要乘一次 f′(z)。如果每层的导数普遍是 0.2，传过 10 层就剩 0.210 ≈ 一千万分之一——底层拿到的训练信号约等于零，权重几乎不更新。这就是梯度消失：不是算错了，是信号在乘法链里衰减没了。

现在回看第 3 节的导数曲线就清楚了：Sigmoid 的导数最大才 0.25，且大部分区域远小于此；Tanh 好一点（峰值 1），但只在零附近陡，两端照样趴平。而 ReLU 正区导数恒为 1——乘多少次都是 1，信号原样通过。下面的模拟器把这件事量化了：一个随机初始化的深网络（Xavier 初始化，宽度 32），我们把单位梯度从顶层灌入，测量它传到每一层时还剩多少。

几个值得动手验证的现象：

  • Sigmoid + 20 层：底层梯度通常衰减到 10⁻⁸ 以下——这正是 2010 年前“深网络训不动”的直接原因。
  • ReLU 同深度：衰减主要来自被置零的那一半神经元和权重尺度，量级上远好于 Sigmoid；配合合适初始化基本可以维持梯度量级。但注意“死区占比”读数——负区导数为 0 是它换来畅通的代价，运气不好时表现为 dead ReLU。
  • 拖动“初始化尺度”：调小，所有函数都更快消失；调大，ReLU 甚至会梯度爆炸（曲线朝上翘）。这提示梯度消失/爆炸从来不是激活函数一个变量决定的——初始化、深度、归一化、残差连接都在同一个乘法链里。激活函数决定的是 f′(z) 这一项的“天花板”。
为什么现代深网络能到几百层？不是因为找到了完美激活函数，而是多管齐下：ReLU/GELU 保住 f′ 的量级 + He/Xavier 初始化保住 W 的量级 + BatchNorm/LayerNorm 持续校正分布 + 残差连接给梯度开了一条不经过任何激活函数的直通旁路（∂(x+F(x))/∂x = I + …，恒有一条“乘 1”的路径）。激活函数是必要条件，不是全部答案。

  • 回答 N 个独立的是非题：“有猫吗？有狗吗？”
  • 一张图可以同时“有猫 0.9、有狗 0.8”
  • 适用：二分类（单输出）、多标签分类

Softmax · 全体竞争一个名额

  • 作用于整个向量，输出强制和为 1，类别互斥
  • 回答一道单选题：“这张图最可能是哪一类？”
  • “猫 0.9”必然压低其他所有类别的份额
  • 适用：单标签多分类、语言模型下一个 token
判断口诀：类别可以同时成立 → 各自 Sigmoid；类别有且只有一个成立 → Softmax。另外二分类里“单输出 Sigmoid”和“双输出 Softmax”数学等价，惯例用前者。
隐藏层激活 vs 输出层激活：两个不同的问题 ›

隐藏层 · 为学习服务

  • 目标：非线性表达力 + 梯度畅通
  • 不关心输出数值的“含义”，只关心分布和导数
  • 默认 ReLU / GELU / SiLU；几乎不用 Sigmoid，绝不用 Softmax
  • 可以整网统一换掉，属于超参数

输出层 · 为语义服务

  • 目标：让输出匹配目标值的类型与范围
  • 由任务+loss 成对锁定，不是调参自由度
  • 回归 Linear；二分类/多标签 Sigmoid；多分类 Softmax
  • 训练时常被折叠进 loss，代码里“看不见”（见下）
关于 logits 的重要工程事实：现代框架里，输出激活经常不显式出现在模型代码中。PyTorch 的 CrossEntropyLoss 内部自带 log-softmax，BCEWithLogitsLoss 内部自带 sigmoid——它们都直接接收原始 logits，在 log 空间合并计算以保证数值稳定。所以训练时模型最后一层就是裸的 Linear；Softmax/Sigmoid 只在推理阶段需要“人类可读的概率”或需要采样时才显式调用。语言模型同理：训练时 logits 直接进 loss，采样时才做 softmax（还常配 temperature）。
SECTION 06

工程实践中的选择规则

下面是实用的默认值，不是铁律——它们成立的前提写在括号里：

  • MLP / CNN 隐藏层：ReLU 是强基线。先用它把 pipeline 跑通；只有当你观察到大量死神经元或训练不稳时，才值得试 Leaky ReLU / GELU（收益通常是小幅的）。
  • Transformer：GELU 或 SiLU。跟随架构惯例——BERT/GPT/ViT 用 GELU，LLaMA 系的 SwiGLU 用 SiLU。复现论文时保持一致，别自作主张换。
  • RNN / LSTM / GRU：Sigmoid 和 Tanh 在这里不是遗产，是语义。门必须输出 (0,1) 的“开度”→ Sigmoid；状态必须有界防爆炸 → Tanh。这是结构设计，不要替换成 ReLU。
  • 输出概率：二分类 → 单输出 Sigmoid；互斥多分类 → Softmax；多标签 → 逐标签 Sigmoid。训练时优先用带 logits 的 loss（BCEWithLogitsLoss、CrossEntropyLoss），别手写 softmax + log。
  • 回归输出：Linear。目标有物理范围时，可用 Sigmoid/Tanh 压缩后再线性缩放到目标区间（例如像素值、角度），但注意目标贴近边界时会进入饱和区、训练变慢。
  • 训练不动别只怪激活函数。梯度消失/爆炸是乘法链整体的问题：检查顺序应该是学习率 → 初始化 → 归一化层 → 残差连接 → 然后才是激活函数。深网络里这五件事是一个系统。
SECTION 07

常见误区与反例

误区一：“Sigmoid 输出像概率，所以隐藏层也用它。”

隐藏层根本不需要“像概率”——它需要的是梯度能通过。Sigmoid 导数上限 0.25 + 两端饱和 + 非零中心，三个问题在隐藏层全数发作，深一点就训不动。概率语义只在输出层有价值。

误区二：“ReLU 一定最好，无脑用。”

ReLU 是好默认，不是最优解：Transformer 里 GELU/SiLU 表现更稳已是共识；RNN 门控里换成 ReLU 会破坏门的语义还可能状态爆炸；学习率偏大时 dead ReLU 会实际发生。“强基线”意味着从它出发，不意味着到它为止。

误区三：“分类网络最后必须手写一层 Softmax。”

训练时通常恰恰不能写：CrossEntropyLoss 接收的是 logits，模型里再加 Softmax 等于做了两次，轻则数值精度受损，重则训练明显变差。这是新手最常见的 bug 之一。Softmax 属于推理/解释阶段。

误区四：“梯度消失是激活函数导致的。”

只对了一小半。梯度是“逐层乘 f′(z) 再乘 W”的连乘，初始化尺度、网络深度、有无归一化和残差连接每一项都在链条里（第 4 节的模拟器里拖动初始化尺度即可验证：同一个激活函数既能消失也能爆炸）。把 Sigmoid 换成 ReLU 只是修好了其中一环。

误区五：“激活函数越新、越复杂越好。”

从 ReLU 到 GELU 的典型增益是零点几个点，且依赖架构与任务；而它带来的差异远小于学习率、初始化或数据质量一档的差异。选择激活函数看三样：任务语义（输出层）、架构惯例（隐藏层）、训练稳定性——不看发表年份。

自检：合上页面能答出来吗

为什么 100 层不带激活函数的网络等价于 1 层？

线性变换的复合仍是线性变换：W₂(W₁x+b₁)+b₂ = (W₂W₁)x + (W₂b₁+b₂)。所有层可以合并成一个 W′x+b′，函数空间没有扩大，只能表达线性映射。

Sigmoid 作为隐藏层的三个问题分别是什么？

① 两端饱和，导数趋零，该层停止学习；② 导数上限仅 0.25，链式连乘导致梯度指数衰减；③ 输出非零中心（恒正），下层权重梯度被迫同号，更新走之字形。

ReLU 为什么缓解梯度消失？代价是什么？

正区间导数恒为 1，梯度穿过激活层不衰减，切断了“乘一串小于 1 的数”的衰减机制。代价是负区导数为 0：神经元若长期落在负区，梯度永远进不来，即 dead ReLU。

多标签分类为什么用多个 Sigmoid 而不是 Softmax？

多标签的各类别可以同时成立，是 N 道独立是非题；Softmax 强制概率和为 1、类别互斥，会让标签之间错误地互相竞争。独立判断 → 逐标签 Sigmoid + BCE。

用 PyTorch 的 CrossEntropyLoss 时，模型最后要不要加 Softmax？

不要。CrossEntropyLoss = log-softmax + NLL，直接吃 logits。再加一层 Softmax 是重复计算，会损害数值稳定性和训练效果。推理时需要概率再单独做 softmax。

SECTION 08

最小代码示例

三段可直接运行的最小示例。第一段用 NumPy + Matplotlib 复现本文的函数/导数曲线（画一遍印象比看十遍深）：

# 1) 画出主要激活函数及其导数（NumPy）
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-6, 6, 400)
sigmoid = lambda z: 1 / (1 + np.exp(-z))
acts = {
    "Sigmoid": sigmoid(z),
    "Tanh":    np.tanh(z),
    "ReLU":    np.maximum(0, z),
    "GELU":    z * sigmoid(1.702 * z),          # 常用近似 z·σ(1.702z)
    "SiLU":    z * sigmoid(z),
}
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 4))
for name, a in acts.items():
    ax1.plot(z, a, label=name)
    ax2.plot(z[:-1], np.diff(a) / np.diff(z), label=name)  # 数值导数
ax1.set_title("f(z)"); ax2.set_title("f'(z)  ← 梯度消失看这张")
for ax in (ax1, ax2): ax.legend(); ax.grid(alpha=.3)
plt.show()

# Softmax 作用在向量上，单独演示：
def softmax(v):
    e = np.exp(v - v.max())      # 减 max：防止 exp 溢出的标准写法
    return e / e.sum()
print(softmax(np.array([2.0, 1.0, 0.1])))  # [0.66 0.24 0.10]，和为 1

第二段是三种任务的输出层写法。注意共同点：模型的最后一层都是裸 nn.Linear，输出激活被折叠进 loss：

# 2) 输出层三件套（PyTorch）—— 模型末端都是 Linear，激活在 loss 里
import torch, torch.nn as nn

backbone = lambda d_in: nn.Sequential(       # 隐藏层：ReLU/GELU 家族
    nn.Linear(d_in, 64), nn.GELU(),
    nn.Linear(64, 64), nn.GELU(),
)

# —— 二分类：1 个 logit + BCEWithLogitsLoss（内含 sigmoid）
bin_head  = nn.Linear(64, 1)
bin_loss  = nn.BCEWithLogitsLoss()            # 目标 shape (N,1)，取值 0/1
# 推理: prob = torch.sigmoid(logit)

# —— 多分类（单标签，C 类）：C 个 logits + CrossEntropyLoss（内含 log-softmax）
mc_head   = nn.Linear(64, C)
mc_loss   = nn.CrossEntropyLoss()             # 目标是类别下标，shape (N,)
# 推理: prob = logits.softmax(dim=-1)   ← 千万不要在模型里再加 Softmax 层

# —— 多标签（C 个独立是非题）：C 个 logits + BCEWithLogitsLoss
ml_head   = nn.Linear(64, C)
ml_loss   = nn.BCEWithLogitsLoss()            # 目标 shape (N,C)，多个 1 可共存
# 推理: probs = torch.sigmoid(logits)   # 各标签独立，和不必为 1

# —— 回归：Linear 直接输出 + MSE / Huber
reg_head  = nn.Linear(64, 1)
reg_loss  = nn.MSELoss()

第三段验证一个本文反复强调的事实——CrossEntropyLoss 接收 logits，手动加 Softmax 是错的：

# 3) 亲手验证：CrossEntropyLoss 吃的是 logits
logits = torch.tensor([[2.0, 0.5, -1.0]])
target = torch.tensor([0])
ce = nn.CrossEntropyLoss()

correct = ce(logits, target)                  # ✓ 正确：直接传 logits
wrong   = ce(logits.softmax(-1), target)      # ✗ 常见 bug：先 softmax 再传
manual  = -logits.log_softmax(-1)[0, 0]       # 手动展开，验证与 correct 相等
print(correct.item(), manual.item(), wrong.item())
# correct == manual；wrong 的数值和梯度都不同 —— 双重 softmax 会伤训练
