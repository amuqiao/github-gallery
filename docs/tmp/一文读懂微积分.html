一文读懂微积分

微积分只研究一对互逆的问题：知道总量怎么求变化率（微分——把弯的切成直的），知道变化率怎么求总量（积分——把碎条加回整体）。微积分基本定理说：这两台机器互为逆运算。

用一辆车把这句话演出来。左图是里程表读数 s(t)，右图是速度表读数 v(t)。拖动时间，观察两个"巧合"：左图切线的斜率，永远等于右图当前的高度；右图涂色的面积，永远等于左图当前的高度。这不是巧合——这就是整个微积分。

里程表 s(t)：开出了多少 km　蓝线 = 此刻的切线

微分方向（左图 → 右图）：里程曲线此刻的切线斜率 = ? km/h，恰好是速度表读数 v(t) = ?
积分方向（右图 → 左图）：速度曲线下 0→t 的面积 = ? km，恰好是里程表读数 s(t) = ?

速度表其实就是"里程表的导数"：它实时显示里程曲线的斜率。里程表就是"速度表的积分"：它默默把每一小段 速度×时间 累加起来。两块仪表盘各自记录，却永远互相印证——正文要做的，就是把这两台机器拆开看清楚，再证明它们为什么互逆。

LIMIT / 从一个除不了的除法开始

瞬时速度：0/0 的困境与极限的解法

先把问题逼到墙角。测速很简单：平均速度 = 走过的距离 ÷ 花掉的时间。但交警要的不是"这两小时平均 60"，而是"这一瞬间是多少"。套公式试试：瞬间意味着时间间隔为 0，走过的距离也是 0——0/0，除法直接罢工。

这就是微积分诞生的第一现场。它的解法不是硬除，而是换一个问法：间隔不必真的等于 0，让它越来越小，看比值往哪个数靠拢。如果比值稳定地逼近某个确定的数，就把这个数定义为瞬时速度。这个"逼近的目标值"就叫极限（limit）：

瞬时速度 = limΔt→0 [s(t+Δt) − s(t)] / Δt

割线 → 切线：亲眼看着比值收敛

回答的问题：Δt 一路缩小，平均速度这个比值真的会"稳定下来"吗？稳定到几？

例子取 s(t) = t²（一辆匀加速的车）。算 t₀ 时刻的瞬时速度：取一小段 [t₀, t₀+h]，割线斜率 = 这段的平均速度。然后不断把 h 除以 10——

h割线斜率 (平均速度)距离 2t₀ 还差

看右表最后一列：对 s(t)=t²，割线斜率 = 2t₀ + h，误差恰好等于 h 本身——h 每除以 10，误差就除以 10，比值笔直地冲向 2t₀，没有任何犹豫。这就是"极限存在"的样子。也注意：h 从未等于 0，我们从没做过 0/0，只是看清了逼近的目标。极限是一个确定的数，不是"永远到不了"的神秘过程。

把话说完整：极限有严格的 ε-δ 定义（"你要多近我就能多近"的博弈式表述），本文只把它当作可靠的地基使用，不展开。你需要带走的只有一句：微积分的每一个概念，都是某个"越来越小/越来越多"过程的极限值——导数是割线斜率的极限，积分是矩形和的极限。接下来分头拆解。

DERIVATIVE / 微分

导数：以直代曲的许可证

把上一章的定义正式落户。函数 f 在 x 处的导数就是那个极限：

f′(x) = limh→0 [f(x+h) − f(x)] / h

三种身份，同一个数：物理上是瞬时变化率（速度、增长率、边际成本）；几何上是切线斜率；计算上是"局部最佳线性替身"的系数。第三种身份最值钱，值得用显微镜看一眼——

数学显微镜：任何光滑曲线，放大后都是直线

回答的问题："可导"到底承诺了什么？为什么敢用直线代替曲线？

窗口宽度 = ?　窗口内 曲线与蓝色切线的最大偏差 = ?　偏差 ÷ 窗口宽 = ?

把倍率拉满：黑曲线和蓝切线几乎重合。关键在最后一个数——偏差不只是变小，而是比窗口宽度缩得更快（比值也趋于 0）。这就是"可导"的全部承诺：误差是比 h 更高阶的小量。写成式子就是微分记号的真正含义：f(x+h) ≈ f(x) + f′(x)·h，误差可以忽略到"连比例都不剩"。所有线性近似、牛顿迭代、梯度下降，用的都是这张许可证。

dy、dx 到底是什么

有了显微镜的画面，微分记号就不神秘了：dx 是"允许 h 任意小"的语言，dy = f′(x)·dx 是切线上的增量——即真实增量 Δy 的"线性主部"。dy/dx 因此首先是一个整体记号（"对 x 求导"），而不是两个小数字相除；但在单变量下它的分数直觉基本可靠（链式法则 dy/dx = dy/du · du/dx 看起来像约分，换元积分也是同一直觉），这是这套记号流传三百年的原因。边界在多变量：偏导数 ∂y/∂x 绝不能当分数约。

求导法则：一张小抄和一个必须记住的反例

逐个用定义算极限太苦，前人已经把常用结果打包成规则。小抄如下——但先看反例：乘积的导数不是导数的乘积。取 f(x)=x、g(x)=x：f·g = x²，导数是 2x；而 f′·g′ = 1×1 = 1。差得远。正确的乘积法则是"你变我不变 + 我变你不变"两项之和：

法则公式一句话直觉
加法(f+g)′ = f′ + g′变化率可以叠加
乘法(fg)′ = f′g + fg′矩形面积的增量 = 两条窄边条之和（各让一边动）
链式(g(f(x)))′ = g′(f(x)) · f′(x)放大倍率串联相乘（复合系统求导的核心，深度学习反向传播的全部数学）
幂(xⁿ)′ = n·xⁿ⁻¹由乘法法则反复自乘得来
基本函数(sin x)′=cos x　(eˣ)′=eˣ　(ln x)′=1/xeˣ 是"变化率等于自身"的那个函数——这正是 e 的定义性身份

还有一个边界要立牌子：不是所有函数都可导。f(x)=|x| 在 x=0 处连续，但左边斜率 −1、右边 +1，割线极限不收敛到同一个数——尖点处没有唯一切线，显微镜放大后依然是个"折角"而不是直线。记住方向：可导 ⇒ 连续，反过来不成立。

INTEGRAL / 积分

积分：切成碎条，加回整体

换到硬币另一面。现在只有速度表的记录 v(t)，想知道总共开了多远。若是匀速，距离 = 速度 × 时间，一次乘法完事；但速度一直在变，一次乘法用哪个速度都不对。积分的策略和微分如出一辙：把时间切成很多小段——每一小段内速度"几乎没变"，可以放心用乘法——然后把所有小段的距离加起来。切得越细，"几乎"就越名副其实。

画在图上，每一小段的 速度×时间 就是一个窄矩形的面积，总距离就是曲线下的面积。这个"矩形和的极限"就是定积分：

∫ab f(x) dx = limn→∞ Σ f(xᵢ)·Δx　（Δx = (b−a)/n）

黎曼和模拟器：看着矩形和收敛

回答的问题：矩形取多细才够？"取左端点还是右端点"重要吗？

例子取 f(x) = x² + 1 在 [0, 2] 上，真值 = 14/3 ≈ 4.6667（第 4 章会告诉你这个数怎么秒算出来）。

左端点和 = ?　中点和 = ?　右端点和 = ?　真值 = 4.6667
当前所选方法误差 = ?　　左右和之差（夹逼的口子）= ?

三个观察：① f 在 [0,2] 上递增，所以左端点和永远偏小、右端点和永远偏大，真值被夹在中间；② 左右和之差 = [f(2)−f(0)]·Δx = 4·(2/n)，n 翻倍口子就减半——夹逼必然收口，这就是"极限存在"的直观证明；③ 中点法快得多（误差按 1/n² 缩小），拖动 n 对比一下。"取哪个点"在极限意义下不重要，在数值计算里很重要——这正是数值积分算法的起点。

两个立刻要立的边界：其一，积分算的是"有符号面积"。x 轴下方的部分记负——对速度而言，v<0 是倒车，积分给出的是位移（净变化），不是路程；要路程得积 |v|。其二，∫ 号读作"求和的极限"，不是"面积"的同义词。面积只是它在"f≥0"时的几何像；同一台求和机器还能算总用电量（积功率）、总概率（积密度）、总质量（积密度×体积）——凡是"变化率 × 微小区间，再累加"的问题都是积分。

FTC / 微积分基本定理

基本定理：为什么求斜率和求面积互逆

首屏那两个"巧合"现在可以摊开来证了。定义面积函数：A(x) = 从起点积到 x 的面积 ∫₀ˣ f(t) dt。关键一问：A 自己的导数是什么？按定义算：x 往右挪一小步 h，面积多出一根细条，A(x+h) − A(x) = 细条面积。h 很小时，细条近似一个矩形：高 f(x)、宽 h。所以：

A′(x) = limh→0 [A(x+h) − A(x)] / h = limh→0 f(x)·h / h = f(x)

一行除法，两个世界接通：面积函数的变化率，就是曲线此刻的高度。"求面积"这台机器的输出，被"求导"这台机器原样还了回去——它们互逆。

那根细条：基本定理的现场证明

回答的问题：A(x+h) − A(x) ≈ f(x)·h 这个近似到底有多准？除以 h 之后剩下什么？

f(t) 与面积函数的增量（那根细条）

A(x) = ∫₀ˣ f：面积函数自己长什么样

红条真实面积 A(x+h) − A(x) = ?　蓝虚线矩形 f(x)·h = ?　相差 ?
各除以 h： [A(x+h)−A(x)] / h = ?，而 f(x) = ?　→ 把 h 拖到最小，看这两个数会师。右图：A 曲线在 x 处的切线斜率，正是左图此刻的高度。

细条和矩形之间的误差，来自条顶那一小弯——它的面积不超过 (条内 f 的波动)×h，除以 h 后剩下"f 的波动"，而 f 连续意味着波动随 h→0 消失。这就是 FTC 第一形态：d/dx ∫₀ˣ f(t)dt = f(x)。

从"互逆"到"秒算面积"

互逆立刻兑现成一台算面积的机器。既然 A′ = f，那么任何满足 F′ = f 的函数（叫 f 的原函数 / 不定积分）都和 A 只差一个常数（导数相同的两个函数只能整体平移——这是"+C"的来历）。于是：

∫ab f(x) dx = F(b) − F(a)　（F 是 f 的任意一个原函数）　——FTC 第二形态

威力检验：第 3 章那个 ∫₀²(x²+1)dx，黎曼和吭哧吭哧切两百条才逼近的数——现在心算：x²+1 的原函数是 x³/3 + x，代入 F(2)−F(0) = 8/3+2 = 14/3。完。无限求和被一次减法取代，这就是"基本定理"四个字的分量：它让积分表反着抄导数表就能用（见速查表），把"求面积"从体力活变成了查表 + 减法。

OPTIMIZATION / 用起来

极值与优化：导数最值钱的用法

微积分在工程里出场率最高的一幕：找最优——利润最大、误差最小、用料最省。原理一句话：光滑函数在山峰或谷底处，切线必然放平。因为若 f′(c) > 0，往右还能更高，c 就不是峰；f′(c) < 0 同理。所以：

极值点的必要条件：f′(c) = 0（驻点）　——注意是"必要"，不是"充分"

极值探测器：f′ 的符号就是地形图

回答的问题：f′=0 之后还要判断什么？为什么有的驻点不是极值？最值又去哪里找？

例子 f(x) = 3x⁵ − 5x³，f′(x) = 15x²(x−1)(x+1)，在 x = −1, 0, 1 三处切线放平——但三处命运各不相同。

跳到驻点：
f′(x) = ?　地形：?
把点拖到（或跳到）三个驻点，看各自的判词。

三个驻点三种结局：x=−1，f′ 左正右负，上坡转下坡 → 局部最大；x=1，左负右正 → 局部最小；x=0，f′ 两侧都是负 → 只是下坡途中一块平台，切线放平却不是极值（x³ 在原点是同款）。所以完整流程是：f′=0 找嫌疑人 → 查两侧 f′ 符号（或 f″ 符号）定罪。还有一个常被漏掉的角落：本例在整个 [−1.5, 1.5] 上的最大值其实在右端点 x=1.5 处（f≈5.9），比局部最大 f(−1)=2 高得多——求最值 = 驻点、不可导点、端点一起排队比大小，谁都不能免检。

迁移到真实世界只差一步：机器学习里的 loss 函数就是这里的 f，参数就是 x，训练就是"往 f′ 的反方向挪"——只不过维数从 1 变成百万，导数升级成梯度。你在这一章建立的所有直觉（驻点不一定是极值、鞍点、局部 vs 全局）原封不动地搬过去用。

MISCONCEPTIONS / 常见误区

常见误区与反例

每张卡片的标题是一个流传很广的错误说法（✕），点开看正确版本（✓）和一个能当场戳破它的反例。

"导数就是'变化了多少'"

导数是变化率——每单位 x 引起多少 y，自带"每"字，量纲是 y/x。真实的变化量要用它乘上区间：Δy ≈ f′(x)·Δx。

反例：速度 120 km/h 的车，一毫秒里只挪 3.3 cm——变化率很大，变化量可以任意小，两者根本不是一回事。

"极限就是'越来越近但永远到不了'的过程"

极限是一个确定的数：逼近过程的目标值，不是过程本身。第 1 章的表格里，割线斜率的极限就是 2t₀，一个普通的数，可以拿来做任何算术。ε-δ 定义把"逼近"翻译成了完全静态的逻辑条件。

反例：0.999… = 1，不是"无限接近 1"。它是级数 9/10+9/100+… 的极限，而这个极限恰好等于 1，没有缝隙。

"dy/dx 就是两个很小的数相除"

它首先是整体记号"对 x 求导"。dx 不是某个固定的小数（那样误差就消不干净），dy = f′dx 是切线增量、真实增量的线性主部。单变量下分数直觉大体安全（链式法则、换元积分都像约分），这是记号的设计智慧。

反例（边界）：多变量里 ∂z/∂x 当分数约会翻车——热力学恒等式 (∂x/∂y)(∂y/∂z)(∂z/∂x) = −1 而不是"约分得 1"。分数直觉止步于偏导数。

"f′(c)=0 就说明 c 是极值点"

f′=0 只是必要条件，只负责"抓嫌疑人"。定罪要看两侧 f′ 符号是否翻转（或 f″ 的符号）；而且最值还可能藏在端点和不可导点，它们连 f′=0 都不满足。

反例：第 5 章的 x=0——f′(0)=0，但两侧都下坡，只是个平台；而全区间最大值在端点 x=1.5，f′ 在那里根本不为零。

"连续的函数当然可导"

方向只有一边：可导 ⇒ 连续。反过来大量反例：连续但带尖点、折角的函数处处存在。

反例：|x| 在 0 处连续，但左斜率 −1、右斜率 +1，极限不统一，不可导。极端反例是 Weierstrass 函数：处处连续、处处不可导——放大到任何倍率都是毛刺，显微镜永远看不到直线。

"积分就是求面积"

积分是"变化率 × 微小区间再累加"的极限，面积只是 f≥0 时的几何投影。x 轴下方计负（有符号面积）；应用里它算的是位移、电量、概率、质量——一切累积量。

反例：∫₀²π sin x dx = 0——上下两瓣面积精确抵消。一辆先前进后倒车回到原地的车：位移（∫v）为 0，路程（∫|v|）不为 0。混淆两者，答案差出天际。

"+C 是个应付检查的形式符号"

它表达一个事实：导数相同的函数是一整族（互相只差常数平移——里程表清没清零，速度表看不出来）。C 由额外信息（初始条件）唯一确定，这正是解微分方程时"初值"存在的意义。

反例：已知 v(t)=2t，s(t) = t²+C；再给"t=0 时已开出 5 km"，C=5 就定死了。丢掉 C，等于宣称所有车出发时里程表都是零。

"学微积分 = 背导数表和积分表"

表只是缓存。核心是两个可迁移的思想：局部以直代曲（微分：一切光滑变化在小尺度上是线性的）和切碎求和取极限（积分：一切累积量都能这样算），外加把两者扣在一起的基本定理。表忘了可以查，思想忘了才是真忘。

反例：cos(x²) 的原函数不在任何初等函数表里（查不到！），但 ∫₀¹cos(t²)dt 照样能用黎曼和算到任意精度，d/dx∫₀ˣcos(t²)dt = cos(x²) 照样由 FTC 秒答——思想在，表缺一页无所谓。

    slope = (f(x0 + h) - f(x0)) / h       # 割线斜率
    print(f"h=1e-{k}  slope={slope:.8f}  err={abs(slope-exact):.2e}")

8.2 积分：黎曼和收敛 + 左右夹逼（对应第 3 章）

f = lambda x: x*x + 1
a, b, exact = 0.0, 2.0, 14/3

for n in [10, 100, 1000, 10000]:
    dx = (b - a) / n
    left  = sum(f(a + i*dx)       * dx for i in range(n))
    right = sum(f(a + (i+1)*dx)   * dx for i in range(n))
    mid   = sum(f(a + (i+0.5)*dx) * dx for i in range(n))
    print(f"n={n:5d}  left={left:.6f} < 真值 < right={right:.6f}   mid_err={abs(mid-exact):.2e}")
# left 恒偏小、right 恒偏大（f 递增），口子 = 4/n；mid 误差按 1/n² 掉

8.3 基本定理：求导和求积分真的互相抵消（对应第 4 章）

python · 数值验证 d/dx ∫₀ˣ cos(t²)dt = cos(x²)
import math

def A(x, n=20000):                       # 面积函数：只会黎曼和也够用
    dx = x / n
    return sum(math.cos(((i+0.5)*dx)**2) * dx for i in range(n))

x, h = 1.3, 1e-4
lhs = (A(x + h) - A(x - h)) / (2*h)     # 对面积函数数值求导
rhs = math.cos(x*x)                     # FTC 的预言
print(lhs, rhs, abs(lhs - rhs))         # 两数在小数点后 6 位一致
# cos(x²) 没有初等原函数、任何积分表都查不到 —— 但 FTC 照常成立

四条随身法则：

  1. 微分 = 以直代曲——可导的承诺是"误差比 h 高阶"，一切线性近似由此签发。
  2. 积分 = 切碎、乘、加、取极限——凡"变化率×小区间再累加"的量都归它管，面积只是其中一张脸。
  3. FTC = 两台机器互逆——面积函数的斜率是当前高度；于是无限求和坍缩成 F(b)−F(a) 一次减法。
  4. f′=0 只抓嫌疑人——定罪看两侧符号，最值还要叫上端点和不可导点一起比。
