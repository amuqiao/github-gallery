# 模型提示词模板 - 一文读懂版

本文维护 AI 模型类《一文读懂》专项提示词，重点补充模型任务、输入输出、数据流、训练/推理差异和工程使用边界。

使用方式：直接复制下面代码块作为完整提示词使用；模型名称、论文、仓库、权重或部署上下文由具体生成任务补充。

## 提示词

```md
为指定模型生成《一文读懂》单文件交互式 HTML，核心目标是让读者快速理解模型解决什么任务、输入输出是什么、数据如何在模型中流动，并能判断是否适合使用、部署或借鉴。

建议：
- 从模型要解决的真实任务切入，先讲清它为什么出现、输入是什么、输出是什么、边界在哪
- 围绕核心数据流展开，讲清从原始输入到最终输出的关键阶段、表示变化、模块分工和因果关系
- 可根据模型特点灵活调整结构，怎么好懂怎么来，避免把文章写成论文复述或术语清单
- 重视训练与推理的区别：讲清训练时学什么，推理时算什么，哪些参数、数据或环境会影响结果
- 重视对比和边界：讲清相近模型、前后版本、常见误区、适用/不适用场景和工程取舍
- 重视可视化：用数据流图、结构图、张量/特征变化、输入输出对照、模块高亮或流程图呈现抽象关系
- 善用交互：可通过步骤切换、悬停提示、展开详情、参数演示、模块追踪、案例对照等方式让读者主动探索
- 示例尽量真实、最小、可验证，可包含最小推理代码、输入准备、输出解释、模型文件结构、部署方式或运行日志
- 单文件内联资源，离线可打开，自然中文表达即可，专业术语、模型名、命令、代码、框架名保留英文
- 首屏视觉贴合模型本身，让人一眼抓住模型任务、输入输出和核心处理路径
```

## 维护规则

- 本模板只维护模型的对象差异：任务边界、输入输出、数据流、模块分工、训练/推理差异和工程取舍。
- 模板正文必须保持可独立复制使用，不依赖其他提示词片段。
- 如果某个要求只适用于特定模型族、框架或部署环境，优先放进具体生成任务，不要写进通用模板。
- 如果后续需要更细的论文解读、数学推导或部署检查清单，单独新增专项片段，不要把本模板变成论文复述模板。
