# 工程实现与方案选型补充提示词

本文维护《一文读懂》生成任务的可选追加片段，用于在任意专项提示词末尾补充工程实现和方案选型视角。

使用方式：先复制对应专项模板的完整提示词，再把下面代码块追加到末尾。本文不是独立生成入口，也不绑定特定知识点、模型、工具或技术栈。

## 提示词

```md
补充工程实现与方案选型部分，目标是让读者在理解主题后，能判断如何在真实项目中落地。

建议：
- 先说明落地边界：真实项目中它通常接收什么输入、产出什么结果、依赖哪些前置条件，以及哪些问题不应由它解决
- 给出最小实现路径：按数据流讲清从输入准备、核心处理、后处理到输出交付的主链路，不展开完整项目脚手架
- 补充方案选型：对比常见实现方式，说明各自适用场景、主要成本、关键限制和不推荐使用的情况
- 给出推荐路径：按 2-3 个典型场景给出建议方案，并解释为什么这样选
- 如有代码或伪代码示例，保持短小可读，只展示主链路、关键输入输出和核心决策；不要加入 silent fallback、吞错默认值或无需求的降级逻辑
```

## 维护规则

- 本文只维护工程落地和方案选型视角，不维护具体领域原理。
- 本文必须保持短小、通用、可追加，不依赖某个固定模板、主题或技术栈。
- 特定语言、框架、模型、云服务或行业场景要求，应在具体生成任务中补充，不写进本文。
