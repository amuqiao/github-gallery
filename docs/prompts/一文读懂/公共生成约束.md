# 一文读懂公共生成约束

本文只沉淀“一文读懂”单文件交互式 HTML 的跨模板写作经验，不作为生成入口，也不被专项模板引用组合。维护专项模板时可借鉴本文方向，但专项模板必须独立包含完整可复制提示词。

使用方式：生成时直接使用对应专项提示词文档的代码块；本文只供维护模板时参考。

## 公共经验

1. 建立心智模型，不写百科摘要或静态展示页。
2. 围绕一个核心对象、核心流程或状态变化组织全文，先讲主干，再展开分支。
3. 首屏贴合主题本体，优先让读者看见核心问题、运行路径、输入输出关系或关键机制。
4. 可视化和交互只服务理解、对比、验证和迁移，避免无关动效和装饰性控件。
5. 示例尽量真实、最小、可验证；单文件内联资源，离线可打开。
6. 维度按主题特点取舍，不机械逐项展开，保留生成模型根据具体对象安排章节的空间。

## 维护规则

- 本文只保留跨模板的历史经验和方向原则，不作为专项模板的索引、依赖入口或组合前缀。
- 专项模板必须独立维护完整提示词正文，使用者应能直接复制对应代码块。
- 如果某个经验只适用于一类主题，优先放进对应专项模板。
- 本文不维护完整生成提示词，避免扩展成第二套模板体系。
