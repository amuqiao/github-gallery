# 读者背景提示词模板

本文维护《一文读懂》生成任务的读者背景补充片段，只用于告诉 LLM 读者是谁，不负责规定具体写作结构。

使用方式：复制下面代码块，追加在具体对象模板前或生成任务开头。本文中的 `md` 代码块是可复制提示词。

## 可追加片段：Python 后端转机器学习

```md
读者背景：我是 Python 后端开发者，熟悉 FastAPI、API、数据库、CRUD、任务队列、日志、部署和基础工程实践；我能理解工程里的输入输出、数据流、依赖、接口契约、调试和上线问题。

我的 AI / ML / DL 基础并不系统：了解一些算法、机器学习和深度学习名词，但数学、数据处理、模型训练、评估指标和论文语境都比较薄弱，没有系统读过研究生课程。

请按“有工程经验，但 AI 基础不系统”的读者来讲解：不要从零基础科普开始，也不要写成研究生教材；优先通过具体案例带出概念，在案例中补齐必要的术语、基础知识、数据概念、模型概念和评估方法。
```

## 维护规则

- 本文只维护读者背景，不维护知识点、算法、模型、工程链路或写作结构。
- 代码块内保持简短，避免反客为主。
