## 3. 常见激活函数家族地图
按“解决的问题”组织，不要只按出现时间罗列。

- Linear / Identity：适合作为回归输出，不适合作为隐藏层主力
- Sigmoid：

  - 适合二分类概率输出
  - 饱和区、梯度消失、非零中心问题
- Tanh：
  - 输出范围 `(-1, 1)`
  - 零中心优于 Sigmoid
  - 仍有饱和和梯度消失
- ReLU：

- SiLU / Swish：
  - 作为平滑激活的补充说明
  - 与 GELU 做简洁对比
- Softmax：

  - 讲清它和 Sigmoid 的输出层差异
